## 3. Какие данные обрабатываются

### 3.1. Основная программа «Офис ВЕГА»

Программа в части офисных приложений работает локально на устройстве Пользователя.

Оператор **не собирает, не передаёт, не хранит и не анализирует** следующие сведения:

- данные о компьютере или ином устройстве Пользователя;
- IP-адрес;
- сведения об операционной системе;
- уникальные идентификаторы устройства;
- сведения об установленных программах;
- историю работы в Программе;
- данные об использовании функций Программы;
- содержимое документов, создаваемых или открываемых Пользователем;
- технические журналы, отчёты об ошибках и сбоях;
- диагностические сведения;
- данные аналитики и телеметрии.

Программа не использует системы скрытого сбора статистики, средства аналитики, рекламные идентификаторы, трекеры и иные механизмы, предназначенные для сбора информации о Пользователе или его устройстве.

### 3.2. ИИ-чат

Для создания и использования учётной записи в ИИ-чате Оператор обрабатывает только адрес электронной почты Пользователя.

**Категория обрабатываемых персональных данных:**

- адрес электронной почты.

Оператор не запрашивает и не обрабатывает для целей авторизации:

- фамилию, имя, отчество;
- номер телефона;
- паспортные данные;
- адрес проживания;
- платёжные реквизиты;
- сведения о компьютере, браузере или операционной системе;
- данные о сбоях и технические отчёты;
- иные персональные данные, кроме адреса электронной почты.

Адрес электронной почты не используется для рекламных рассылок без отдельного согласия Пользователя.

## 6. Обработка запросов в ИИ-чате

### 6.1. Передача промптов

Для ответа ИИ-чата Пользователь самостоятельно направляет промпты в выбранную модель искусственного интеллекта через API VEGA.

Промпты могут включать текст, фрагменты документов, вопросы, команды и иные данные, которые Пользователь по собственной инициативе передаёт в ИИ-чат.

Оператор рекомендует не направлять в ИИ-чат:

- специальные категории персональных данных, включая сведения о здоровье, политических взглядах, религиозных убеждениях и интимной жизни;
- биометрические персональные данные;
- паспортные данные;
- данные банковских карт;
- пароли, ключи доступа, токены, секреты и иную конфиденциальную информацию;
- персональные данные третьих лиц без наличия законного основания для их передачи;
- сведения, составляющие коммерческую, служебную, банковскую, врачебную или иную охраняемую законом тайну.

### 6.2. Передача данных через API VEGA

Для выполнения запроса Пользователя содержание промпта передаётся по защищённому каналу связи в сервис API VEGA: `https://api.vega.chat`.

API VEGA является прокси-провайдером, обеспечивающим доступ к различным моделям искусственного интеллекта. В зависимости от выбранной Пользователем модели содержание промпта может направляться соответствующему поставщику модели исключительно для формирования ответа.

Оператор исходит из того, что API VEGA использует режим **ZDR (Zero Data Retention)**, то есть режим отсутствия хранения содержания запросов Пользователя после их обработки, если такой режим предусмотрен для выбранной модели и применяемого поставщика.

При этом Пользователь понимает, что:

- содержание промпта передаётся за пределы Программы, поскольку это необходимо для получения ответа от модели искусственного интеллекта;
- промпты не являются данными, необходимыми для регистрации в ИИ-чате;
- Пользователь самостоятельно определяет содержание направляемых промптов;
- если Пользователь указывает в промпте персональные данные, такие сведения могут обрабатываться поставщиком выбранной модели в объёме, технически необходимом для выполнения запроса;
- перед направлением персональных данных третьих лиц Пользователь обязан убедиться в наличии законного основания для такой передачи.

### 6.3. Отсутствие хранения промптов Оператором

Оператор не использует содержание промптов для рекламы, профилирования, обучения собственных моделей искусственного интеллекта или формирования пользовательских профилей.

Оператор не осуществляет постоянное хранение содержания промптов и ответов ИИ-чата, если иное прямо не указано в функциональности соответствующей версии Программы или не требуется законодательством Российской Федерации.

Документы и результаты работы, сохранённые Пользователем на своём устройстве, хранятся на устройстве Пользователя либо в выбранном им хранилище. Оператор не получает к ним доступ, если Пользователь самостоятельно не направит их в ИИ-чат или службу поддержки.
