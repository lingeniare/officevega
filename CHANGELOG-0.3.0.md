# OfficeVega 0.3.0 — полный changelog

- **Релиз:** 2026-11-04, инсталлер `OfficeVega Setup 0.3.0.exe` (Windows x64).
- **База сравнения:** 0.2.0 (опубликована 2026-10-19, коммит `bc93f8da`).
- **Объём:** 259 коммитов — ~109 новых возможностей, ~114 исправлений, остальное тесты/инфраструктура.
- **Upstream:** включены три синхронизации с genoffice (`28cee5ca`, 111 коммитов по 30.10, 79 коммитов по 02.11 = v0.12.600) и пять snapshot-синков (15.10 → 02.11). Коммиты «Sync snapshot» — это пакетные синхронизации апстрима.

---

## Главное

- **Тихие обновления:** новая версия скачивается в фоне и ставится при выходе из приложения, не перебивая работу; отдельная настройка отключает автоматические проверки совсем (#2399, #2127).
- **Импорт legacy-форматов:** файлы `.doc`/`.dot` и корейские `.hwp`/`.hwpx` открываются через автоматическую конвертацию в `.docx` — внутри полноценный движок разбора `.doc` (OLE2/CFB → текст → форматирование → таблицы → картинки → списки) (#2370–#2383, #2386, #2387, #2404).
- **Docs:** вкладка «Рассылки» — слияние документа с локальным источником данных, вывод на листы наклеек и конверты; сравнение двух документов в режим отслеживаемых правок; картинки в комментариях; мультивыделение Ctrl/Cmd+клик (#2122, #2374, #2119, #2376, #2016).
- **Sheets:** панель внешних связей с пересчётом значений, зашифрованные книги и смена пароля, What-If таблицы данных, валидация x14, проверка орфографии, картинки в ячейках и заметках, импорт картинок/объединений/размеров из legacy `.xls` (#2343, #2319, #2136, #2229, #2224, #2227, #2042, #2165, #2302).
- **PDF:** сравнение документов постранично на уровне текста, панель вложений, измерительный инструмент с калибровкой, OCR-текст в сохраняемом файле, сжатие размера, редактируемые закладки, нумерация Bates, гиперссылки, панель комментариев (#2251, #2250, #2252, #2254, #2255, #2203, #2247, #2192, #2193).
- **Slides:** настоящие 3D-модели как в PowerPoint, лента редактирования мастера слайдов, запись слайд-шоу с озвучкой, размеры A4/A3/портрет/произвольный, экспорт страниц в JPG (#2091, #2178, #2056, #2191, #2330).
- **Markdown:** wiki-связи `[[…]]` и встраивание `![[…]]` с автодополнением, бэклинки и граф связей, block-id и ссылки на блоки, сайдбар тегов, сноски, `==подсветка==` (#1996, #1998, #2268, #2256, #2213, #2200).
- **AI:** новые провайдеры SiliconFlow, PPIO, Command Code, CloudGPU, Runcrate; Kimi K3.1 Pro; поисковый бэкенд Keenable; маршрут решений через OpenAI Decisions API; генерация и поиск картинок в HTML-документах (#2439, #2310, #2217, #2189, #2124, #2190, #2180).
- **MCP/CLI:** вставка картинок в документ, sheet_links для внешних связей, fill_template, read_docx_properties, сохранение и закрытие вкладок через open_documents, конвертация .doc в CLI (#2267, #2408, #2409, #2047, #2048, #2386).

## Shell — оболочка, обновления, окна

**Новое**

- Фоновая загрузка обновления с установкой при выходе; настройка «Устанавливать обновления автоматически» (#2399).
- Настройка «Проверять обновления автоматически» (#2127/#2188).
- Проверка орфографии следует за языком интерфейса, а не только за языком ОС (собственная доработка).
- AI-именование файлов: приложение предлагает имя, когда пользователь просит — shell и все редакторы (#2156–#2161, #2321).
- Импорт уже имеющихся document skills (#1895); установка skills в общий каталог `~/.agents` с отдельной строкой на каждый инструмент (#2281).
- Каталог skills: вкладка «Все» и локализованные описания (#2438).
- Список диалогов панели базы знаний (#2069); панель сохраняет свой тред (#2068).
- Запоминание положения и размера окна между сессиями (#2066); переоткрытие документов прошлой сессии при запуске (#2162/#2187); сайдбар главного экрана тянется за край (#2169/#2186).
- Единый пункт «Настройки» (Ctrl/Cmd+,) в меню каждого приложения (#2110).
- Decision-модели от Perplexity, Liquid и Cloudflare в настройках (#2073); маршрут OpenAI Decisions API (#2190).
- Шаблоны «Создать» для KDE Dolphin на deb/rpm-пакетах Linux (#2403).

**Исправления**

- Иконка AI-меню PDF снова видна при 100% DPI (#2133/#2207).
- Локальные (loopback) провайдеры больше не идут через прокси главного процесса (#2095).
- Запуск не падает при запрещённой папке сохранения; на Windows принимается host-собранный xlsx-sidecar (#2087).
- Тема подложки красится до загрузки рендерера — нет белой вспышки (#2130).
- Контекстное меню дерева папок открывается справа от курсора (#2131).
- У AI-вызова именования файла есть место под reasoning (#2361).
- Центрирование бейджей шага «Ask your knowledge base» (#2401).
- Тесты: форматирование списка docx-семейства, таймер ошибок resume-загрузки (#2429, #2232).

## Docs — текстовый редактор

**Новое**

- Открытие legacy `.doc`/`.dot` через конвертацию в `.docx` (#2387); движок `doc2docx` — 8 стадий от OLE2/FIB/CLX до списков и HYPERLINK-полей (#2370–#2383).
- Открытие `.hwp`/`.hwpx` через конвертацию (#2404).
- Вкладка «Рассылки»: слияние с локальным источником данных (#2122); вывод на листы наклеек и конверты (#2374).
- Сравнение двух документов в redline с отслеживаемыми правками (#2119).
- Картинка в комментарии (#2376); Ctrl/Cmd+клик — несмежное выделение (#2016).
- Чтение/запись свойств документа — core, app, custom (#2111); типизированные custom-свойства и Word-подобные docProps при создании (#2354).
- Блочные content controls — чтение и запись (#2118); отчёт по вложенным и инлайновым контролам (#2356).
- `remove_parts` — вычистка customXml и web-extension частей для чистки метаданных (#2351).
- Поворот плавающих фигур и настройка толщины контура (#2266/#2305); хром выделения поворачивается вместе с фигурой, у колонтитулов сохраняются transform и обводка (#2309).
- Маркеры, нумерация и отступ внутри текстовых полей и фигур (#2195).
- Mind map: переключение раскладки «сверху-вниз / слева-направо» (#2397; общее ядро — #2395).

**Исправления**

- Картинки в колонтитулах двигаются и ресайзятся как в Word; брошенные картинки держат свою страницу (#2322); плавающие картинки в ранах редактируются, двигаются и перевыбираются (#2293).
- Нетронутые таблицы сохраняются байт-в-байт (#2405); сетка ширины таблицы сохраняется при удалении колонок (#2238); `deleteTableColumn` — обычная команда (#2258).
- Разрыв страницы не уезжает при редактировании соседнего текста (#2324); раскладка абзацев сохраняется при структурных правках (#2411); gap-заголовки выровнены с колонками разметки (#2412).
- Режим выносок перепагинирует так, что удалённые балуны видны (#2806/#2441); целые абзацы в сравнении едут на знаке абзаца (#2299).
- Объединённая группа через разрыв страницы держит строки по высоте контента (#2154).
- Заголовок переживает сохранение в документе без стилей заголовков (#2215); подписи SEQ экранируются (#2206); вставленное поле держит свою инструкцию (#2108).
- DOCX→PDF: SECTIONPAGES, лидеры TOC кастомных стилей, page-anchored фигуры, Type3 CJK-шрифты (#2331/#2364); CJK-слоты шрифтов для имён семейств (#2392).
- Zotero-данные пишутся в формате хранилища файла (#2092); подсчёт слов AI-снапшота как в статус-баре (#2074); отслеживаемое сохранение-перезагрузка (#2279); «Сохранить как» доступно при непригодной папке по умолчанию (#2433).
- Плавающая позиция только что вставленных картинок переживает сохранение (#2182); fold-хэндлы в режиме структуры складывают (#2183).
- Тесты: seeded round-trip fuzz DOCX-пайплайна (#2445), обновление golden-базлайнов (#2427/#2428), фиксация #524 byte-confinement (#2352), уничтожение редакторов в тестах (#2348).
