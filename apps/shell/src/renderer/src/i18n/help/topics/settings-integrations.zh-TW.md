# 設定、語言、主題與 MCP 整合

## 開啟設定

點選首頁左下角的帳戶列即可開啟設定面板（未登入時顯示為「登入」）。面板共分六個區段：帳戶、AI 模型、AI 生圖與搜尋、一般、整合、關於。

![設定 ▸ 一般：語言、主題與自動儲存都在這裡](img/settings-general.png)

模型配置另有專門一章。**AI 生圖與搜尋**則是依服務商分別開啟圖像生成、圖像分析、影片分析、網路搜尋與本機檔案搜尋的地方。

## 語言

- 設定中可選擇 **21 種介面語言**：English、简体中文、日本語、한국어、Français、Deutsch、Español、ไทย、Bahasa Indonesia、Русский、العربية、Português、Italiano、Polski、Čeština、Nederlands、Bahasa Melayu、עברית、हिन्दी、繁體中文、Tiếng Việt。
- 切換後立即生效並會保留；原生選單列也會隨語言重新建立。

## 主題

淺色／深色／跟隨系統三種。跟隨系統時會依作業系統的外觀切換，編輯器區域同步換膚，且不會閃白。

## 一般

- **傳送匿名使用統計**：預設開啟。使用 Google Analytics 4，會傳送你的公開 IP 位址與傳輸中繼資料；文件內容與檔案名稱絕不會被收集，每個事件只帶一種類型，例如「開啟了一個 .docx」。你隨時可以在這裡關閉。
- **AI 側邊欄位置**（左或右）、**AI 面板文字大小**與 **AI 對話拼字檢查**。
- **在新文件中開啟 AI 面板**：關閉時，新文件一開始面板是收合的，點一下即可展開。
- **所有文件自動儲存**會讓每個編輯器預設開啟自動儲存；單一視窗仍然可以關閉。
- **預設儲存位置**搭配**變更**按鈕，以及**設為 Office 文件預設程式**，可讓 .docx / .xlsx / .pptx 由 OfficeVega 開啟。

## AI 生圖與搜尋

這些不是開關。每一項能力都會自行挑選提供服務的供應商，供應商的金鑰與基礎網址只需填寫一次，各欄位共用：

- **網路搜尋**、**生圖**、**圖片分析**與**影片分析**，每一項都有供應商、模型、金鑰與基礎網址。選擇 **VEGA** 作為供應商，即可用你的登入金鑰經由 `api.vega.chat` 運作。
- **本機檔案搜尋**在這台電腦上執行。其下的**Jev 搜尋重排**預設為關閉。開啟後，本機搜尋前 20 筆命中片段（每份文件最多 1,200 個字元，加上檔名與資料夾名稱）會傳送給 TypeSafe 的 Jev 模型，依相關性重新排序。關閉時，不會有任何資料離開本機。

## 關於

- **版本**資訊、專案網站 [officevega.com](https://officevega.com)，以及發布頁 [officevega.com/releases](https://officevega.com/releases)。
- **更新通道**：穩定版或 Beta 版。變更後立即生效並檢查更新；它不會把 Beta 版的安裝降回穩定版。

## 預設應用程式關聯

設定中可以把 .docx / .xlsx / .pptx / .pdf 等格式註冊為由 OfficeVega 開啟（這是作業系統層級的預設應用程式註冊；出現提示時請確認）。

## VEGA 登入

- 登入入口（設定或雲端專案清單）採用**裝置碼**流程：OfficeVega 會顯示一組驗證碼並開啟瀏覽器登入頁；完成後會自動繼續。
- 登入只用於：雲端專案清單，以及 `api.vega.chat` 上的 VEGA 官方代管模型。不登入時，所有本機功能與自訂模型都照常運作。
- 在設定中一鍵即可登出。

## MCP 整合（供進階使用者／AI 用戶端使用）

**整合**是把 OfficeVega 接上程式開發代理的面板，它也有專門一章：連接程式開發代理。簡單來說就是：選一條路（命令列或 MCP），照那一節操作，然後開一個新對話直接提問。

![設定 ▸ 整合：先三個步驟，再是技能列與 MCP 選項](img/settings-integrations.png)

在**本機 HTTP 服務**之下，應用程式也可以自行執行這個服務，包括一個啟用開關與一個連接埠；而**進階**會再加上健康檢查的網址與日誌檔案。它只監聽 localhost。

## 命令列速查

| ------------------ | ------------------- |

| `officevega --help` | 全部命令與參數      |
