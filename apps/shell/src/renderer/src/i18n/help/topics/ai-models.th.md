# โมเดล AI และการตั้งค่า

## ผู้ให้บริการและโมเดล

ตั้งค่าโมเดลและคีย์ได้ในการตั้งค่า (แถวบัญชีที่มุมล่างซ้ายของหน้าแรก):

![หน้าต่างการตั้งค่า](img/settings-general.png)

- **VEGA บนเซิร์ฟเวอร์ของ VEGA**: ลงชื่อเข้าใช้ (ขั้นตอนรหัสอุปกรณ์) แล้วใช้งานได้ทันที ไม่ต้องตั้งค่าอะไรเพิ่ม คำขอจะถูกส่งไปยัง `https://api.vega.chat` ซึ่งเป็นปลายทางที่เข้ากันได้กับ OpenRouter ดังนั้นไคลเอนต์แบบ OpenRouter ใด ๆ ก็สามารถชี้มาที่ปลายทางนี้ได้
- **ปลายทางที่กำหนดเอง (BYOK)**: ใน การตั้งค่า ▸ AI ให้กรอก base URL และคีย์ API แยกตามโปรโตคอล เช่น ที่เข้ากันได้กับ OpenAI, Anthropic, Gemini, DeepSeek, DashScope (qwen) และอื่น ๆ คีย์จะถูกเก็บไว้ในไฟล์การตั้งค่าของแอปบนเครื่องนี้ และส่งไปเฉพาะในส่วนหัวของคำขอ
- เลือกโมเดลต่างกันได้ตามความสามารถ: การสนทนา/การสร้างเนื้อหา, การสร้างภาพ, การวิเคราะห์ภาพ
- **ทดสอบการเชื่อมต่อ**: ตรวจสอบว่าปลายทางเข้าถึงได้และมองเห็นโมเดลก่อนบันทึก
- base URL สามารถมีพาธและ query string ต่อท้ายได้ (แบบเกตเวย์) และพาธของปลายทางจะถูกต่อท้ายอย่างถูกต้อง

## การเลือกโมเดล

- ตัวเลือกโมเดลอยู่ที่ด้านบนของแผง AI และในการตั้งค่า ▸ โมเดล AI โดยเลือกหนึ่งตัวสำหรับการสนทนา และเลือกแยกต่างหากสำหรับการสร้างภาพและการวิเคราะห์ภาพ ในกรณีที่ผู้ให้บริการรองรับ
- เริ่มด้วยโมเดล VEGA เริ่มต้น เหมาะกับงานสำนักงานส่วนใหญ่ (เขียนใหม่ ตาราง สูตร สรุป) เปลี่ยนไปใช้โมเดลที่ใหญ่กว่าเมื่อต้องการการให้เหตุผลที่ซับซ้อนหรือเอกสารยาว และเปลี่ยนไปใช้โมเดลขนาดเล็กที่ถูกกว่าเมื่อต้องการร่างเร็ว ๆ
- การสนทนาที่กำลังดำเนินอยู่จะยังใช้โมเดลเดิมจนถึงรอบถัดไป ส่วนแชตใหม่จะใช้ตัวเลือกใหม่ทันที

## ราคาและการใช้งาน

- การเรียกเก็บเงินของ VEGA เป็นแบบจ่ายตามการใช้งานต่อโมเดล รายการราคาทั้งหมดอยู่ที่ [api.vega.chat/aimodels](https://api.vega.chat/aimodels) ควรตรวจสอบราคาอินพุต/เอาต์พุตของโมเดลก่อนทำงานขนาดใหญ่
- ยอดคงเหลือและการใช้จ่ายปัจจุบันดูได้ที่ [แดชบอร์ด VEGA](https://api.vega.chat/dashboard) ซึ่งเปิดได้จากแถวยอดคงเหลือในเมนูบัญชีเช่นกัน
- หากยังไม่ได้ลงชื่อเข้าใช้ จะใช้ได้เฉพาะตัวเลือกในตัวที่ไม่เสียค่าใช้จ่าย ลงชื่อเข้าใช้เพื่อปลดล็อกโมเดลทุกตัวในรายการราคา

## การผสานรวมกับ CLI (แบบ Codex)

- การตั้งค่ารับพาธของโปรแกรม CLI ในเครื่องได้ (รองรับโฟลเดอร์บ้านที่ไม่ใช่ ASCII และพาธที่ขึ้นต้นด้วย ~ โดย ~ จะถูกขยายให้อัตโนมัติ) ส่วน ตรวจหาโมเดล จะตรวจดูโมเดลที่ CLI มีให้ใช้
- การตรวจสอบจะเช็กเพียงว่ามีพาธนั้นอยู่จริง ไม่มีข้อจำกัดเรื่องชุดอักขระ

## การเปลี่ยนแปลงมีผลเมื่อใด

- การเปลี่ยนโมเดลและปลายทางมีผลทันที การสนทนาที่กำลังดำเนินอยู่จะยังใช้การตั้งค่าเดิมจนถึงรอบถัดไป
