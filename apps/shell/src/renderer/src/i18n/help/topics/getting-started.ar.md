# بدء سريع: الواجهة والأساسيات

OfficeVega حزمة مكتبية تعمل بالكامل على جهازك: نافذة واحدة وصف واحد من علامات التبويب يضم ستة محرّرات — Docs (معالجة النصوص)، وSheets (جداول البيانات)، وSlides (العروض التقديمية)، وPDF، وMarkdown، وHTML. الملفات هي ملفات .docx / .xlsx / .pptx / .pdf حقيقية، ويمكن تبادلها بالكامل مع Word وExcel وPowerPoint. لا يحتاج الأمر إلى اتصال بالشبكة.

## نظرة عامة على الواجهة

![الشاشة الرئيسية](img/home-screen.png)

تتكون النافذة من ثلاثة أجزاء:

- **شريط علامات التبويب (في الأعلى)**: كل ملف مفتوح يظهر كعلامة تبويب. علامة الصفحة الرئيسية في أقصى اليسار موجودة دائمًا ولا يمكن إغلاقها، أما العلامات الأخرى فهي مستنداتك. انقر نقرًا مزدوجًا على علامة التبويب لإعادة تسمية ملفها مباشرة.
- **منطقة المحتوى**: المحرّر (أو الصفحة الرئيسية) الخاص بعلامة التبويب النشطة.
- **شريط القوائم**: في أعلى النافذة على Windows. تتغيّر قوائم ملف / تحرير / عرض لتطابق المحرّر النشط.

## إنشاء مستند

اختر أيًّا مما يلي:

- انقر بطاقة إنشاء سريع في قسم [البدء السريع](help://getting-started) من **الصفحة الرئيسية** (AI Docs، AI Sheets، AI Slides، ...).
- من قائمة **ملف ▸ جديد**: Docs (ctrl+N)، أو Sheets، أو Slides، أو Markdown، أو HTML، أو PDF.
- اسحب ملفًا إلى النافذة، أو انقر عليه نقرًا مزدوجًا في مدير الملفات (إذا كان OfficeVega هو التطبيق الافتراضي).

يُفتح المستند الجديد بدون اسم، ولا يُنشأ الملف على القرص إلا عند الحفظ الأول.

## فتح الملفات

- تفتح قائمة **ملف ▸ فتح** (ctrl+O) منتقي ملفات النظام: .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html.
- انقر أي عنصر في قائمة **المستخدمة مؤخرًا** في الصفحة الرئيسية.
- الأمر `officevega <file>` من الطرفية يفتح الملفات أيضًا.

## نموذج الحفظ

- **الحفظ اليدوي**: ctrl+S، أو ملف ▸ حفظ / حفظ باسم. وفي الحفظ الأول يطلب التطبيق المكان والاسم.
- **الحفظ التلقائي** يُفعَّل فقط بعد أن تحفظ الملف يدويًا مرة واحدة على الأقل، فلن يُعاد كتابة ملف PDF تقرأه فقط بصمت. ويعمل الحفظ التلقائي بعد تغيّر المحتوى بوقت قصير.
- إغلاق علامة تبويب فيها تغييرات غير محفوظة يعرض عليك أولًا خيارات: حفظ / تجاهل / إلغاء.
- كل كتابة تتم بشكل ذرّي (ملف مؤقت ثم إعادة تسمية)، فلا يمكن أن ينقطع التيار ويترك ملفًا نصف مكتوب.

## اختصارات شائعة

| الإجراء             | Windows |
| ------------------- | ------- |
| مستند جديد          | ctrl+N  |
| فتح                 | ctrl+O  |
| حفظ                 | ctrl+S  |
| إغلاق علامة التبويب | ctrl+W  |
| فتح هذا الدليل      | F1      |
| طيّ الشريط          | Ctrl+F1 |

**طيّ الشريط** يعمل في كل المحرّرات. يبقى صف علامات التبويب ويختفي شريط الأوامر الذي تحته. وعلامة التبويب المحددة تعمل أيضًا كزر طيّ، فعندما يكون الشريط مطويًا لا تكون أي علامة محددة، والنقر على أي علامة تبويب يعيد الشريط. النقر المزدوج على علامة تبويب يفعل الشيء نفسه. ويُحفظ الاتجاه الذي تركته فيه لكل محرّر على حدة.

الاختصارات داخل كل محرّر (نسخ التنسيق، والبحث والاستبدال، وعمليات الجداول، ...) مذكورة في فصولها الخاصة. ويتضمن Docs أيضًا نافذة قابلة للبحث لاختصارات لوحة المفاتيح (**ctrl+/**) تغطي اختصاراته كاملة.
