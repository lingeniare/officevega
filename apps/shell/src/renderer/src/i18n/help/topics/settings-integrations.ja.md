# 設定、言語、テーマと MCP 連携

## 設定を開く

ホームの左下にあるアカウントの行から設定パネルを開きます（サインアウトしているときは「サインイン」と表示されます）。セクションは 6 つあります。アカウント、AI モデル、AI メディアと検索、一般、連携、情報。

![設定 ▸ 一般（言語、テーマ、自動保存、利用統計のスイッチがある場所）](img/settings-general.png)

モデルの設定については別の記事があります。**AI メディアと検索**では、プロバイダーごとに画像生成、画像解析、動画解析、Web 検索、ローカルファイル検索をオンにできます。

## 言語

- 設定では **21 種類の UI 言語**から選べます：英語、簡体字中国語、日本語、韓国語、フランス語、ドイツ語、スペイン語、タイ語、インドネシア語、ロシア語、アラビア語、ポルトガル語、イタリア語、ポーランド語、チェコ語、オランダ語、マレー語、ヘブライ語、ヒンディー語、繁体字中国語、ベトナム語。
- 切り替えるとすぐに反映され、保存されます。ネイティブのメニューもその言語で組み直されます。

## テーマ

ライト／ダーク／システムに従う の 3 種類です。「システムに従う」を選ぶと OS の外観に合わせて変わり、エディターの配色も同期して切り替わるため、ちらつきもありません。同じ切り替えで AI パネルとホーム画面の配色も変わるので、アプリ全体が 1 つのデザインにまとまります。明るい部屋にはライト、夜間の作業にはダーク、Windows に合わせるならシステムに従う、という使い分けができます。

## 一般

- **トラッキング用の分析はありません**：OfficeVega には Google Analytics も、サードパーティのトラッカーも含まれていません。文書の内容、ファイル名、利用イベントが収集されたり、どこかに送信されたりすることはありません。
- **AI サイドバーの位置**（左または右）、**AI パネルの文字サイズ**、**AI チャットのスペルチェック**。
- **新しいドキュメントで AI パネルを開く**：オフにすると、新しいドキュメントはパネルを折りたたんだ状態で始まり、ワンクリックで開けます。
- **すべてのドキュメントを自動保存**は、すべてのエディターで自動保存を既定でオンにします。ウィンドウ単位でオフにすることもできます。
- **保存先**（**変更**ボタン）と **Office 文書の既定のアプリ**では、.docx / .xlsx / .pptx を OfficeVega で開くように設定できます。

## AI メディアと検索

スイッチではありません。各機能が、それを担当するプロバイダーを選びます。プロバイダーのキーとベース URL は一度入力すれば、共有されます。

- **Web 検索**、**画像生成**、**画像解析**、**動画解析** には、それぞれプロバイダー、モデル、キー、ベース URL があります。プロバイダーに **VEGA** を選ぶと、サインインのキーを使って `api.vega.chat` 経由で処理されます。
- **ローカルファイル検索** はこのマシンで動作します。その下にある **Jev による再ランキング** は**既定でオフ**です。オンにすると、ローカル検索の上位 20 件の抜粋（各文書は最大 1,200 文字、加えてファイル名とフォルダー名）が TypeSafe の Jev モデルに送られ、関連度順に並べ替えられます。オフのままなら、端末の外に何も送信されません。

## 情報

- **バージョン**、プロジェクトの GitHub リンク、**GitHub でスターを付ける** ボタン。
- **更新チャンネル**：安定版またはベータ版。変更するとすぐに反映され、更新を確認します。ベータ版のインストールを安定版に戻すことはありません。

## 既定のアプリの関連付け

設定から、.docx／.xlsx／.pptx／.pdf などを OfficeVega で開くように登録できます（プラットフォームレベルの既定アプリの登録です。確認が表示されたら承認してください）。

## サードパーティソフトウェアの通知と更新

- ヘルプ ▸ サードパーティソフトウェアの通知：アプリに同梱されている OSS ライセンスの一覧。
- ヘルプ ▸ 更新を確認：手動で更新を確認します。新しいバージョンがあればインストールを促されます。

## VEGA へのサインイン

- サインインの入口（設定またはクラウドのプロジェクト一覧）は**デバイスコード**方式です。OfficeVega がコードを表示し、ブラウザーでログインを開きます。完了すると、自動的に続きが実行されます。
- サインインが使われるのは、クラウドのプロジェクト一覧と、`api.vega.chat` で提供される VEGA のホスト型モデルだけです。サインインしなくても、ローカルの機能とカスタムモデルはすべて使えます。
- サインアウトは設定から 1 クリックでできます。

## MCP の連携（上級者／AI クライアント向け）

OfficeVega をコーディングエージェントに接続するのは **連携** ペインです。これには独立した記事「コーディングエージェントの接続」があります。要点は、方法（コマンドラインか MCP）を選び、その節に従ってから、新しいチャットを開いて質問することです。

![設定 ▸ 連携：まず 3 つの手順、次にスキルの行と MCP のオプション](img/settings-integrations.png)

**ローカル HTTP サーバー** では、アシスタントに任せる代わりに、アプリ自身がサーバーを動かすこともできます（有効化スイッチとポート）。**詳細** には、ヘルスチェックの URL とログファイルが表示されます。サーバーは localhost でのみ待ち受けます。
