# त्वरित प्रारंभ: इंटरफ़ेस और बुनियादी बातें

OfficeVega एक ऑफ़िस सूट है जो पूरी तरह आपकी मशीन पर चलता है: एक विंडो, टैब की एक पंक्ति, और उसमें छह एडिटर — Docs (शब्द प्रसंस्करण), Sheets (स्प्रेडशीट), Slides (प्रस्तुतियाँ), PDF, Markdown और HTML। फ़ाइलें असली .docx / .xlsx / .pptx / .pdf होती हैं, जो Word, Excel और PowerPoint के साथ पूरी तरह इस्तेमाल हो सकती हैं। नेटवर्क की ज़रूरत नहीं।

## इंटरफ़ेस की झलक

![होम स्क्रीन](img/home-screen.png)

विंडो के तीन हिस्से हैं:

- **टैब पट्टी (ऊपर)**: हर खुली फ़ाइल एक टैब है। सबसे बाईं ओर का Home टैब हमेशा रहता है और बंद नहीं किया जा सकता; बाकी टैब आपके दस्तावेज़ हैं। किसी टैब पर डबल-क्लिक करके उसकी फ़ाइल का नाम वहीं बदला जा सकता है।
- **सामग्री क्षेत्र**: सक्रिय टैब का एडिटर (या Home)।
- **मेन्यू पट्टी**: Windows पर विंडो के सबसे ऊपर। File / Edit / View मेन्यू सक्रिय एडिटर के हिसाब से बदलते हैं।

## दस्तावेज़ बनाना

इनमें से कोई भी तरीका अपनाएँ:

- **Home** के [Quick start](help://getting-started) सेक्शन में कोई भी त्वरित-निर्माण कार्ड दबाएँ (AI Docs, AI Sheets, AI Slides, ...)।
- मेन्यू **File ▸ New**: Docs (ctrl+N), Sheets, Slides, Markdown, HTML या PDF।
- कोई फ़ाइल विंडो पर खींचें, या अपने फ़ाइल मैनेजर में उस पर डबल-क्लिक करें (यदि OfficeVega डिफ़ॉल्ट ऐप है)।

नया दस्तावेज़ बिना शीर्षक के खुलता है; डिस्क पर फ़ाइल पहली बार सहेजने पर ही बनती है।

## फ़ाइलें खोलना

- मेन्यू **File ▸ Open** (ctrl+O) सिस्टम चयनकर्ता खोलता है: .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html।
- Home की **Recent** सूची में किसी भी आइटम पर क्लिक करें।
- टर्मिनल से `officevega <file>` भी फ़ाइल खोलता है।

## सहेजने का तरीका

- **मैन्युअल सेव**: ctrl+S, या File ▸ Save / Save As। पहली बार सेव करते समय स्थान और नाम पूछा जाता है।
- **ऑटोसेव** तभी चालू होता है जब आप फ़ाइल को कम से कम एक बार मैन्युअल रूप से सेव कर चुके हों — जो PDF आपने केवल पढ़ी है, उसे चुपचाप दोबारा नहीं लिखा जाता। सामग्री बदलने के कुछ ही देर बाद ऑटोसेव होता है।
- बिना सेव किए बदलाव वाला टैब बंद करने पर पहले पूछा जाता है: Save / Discard / Cancel।
- हर लिखाई परमाणु रूप से होती है (अस्थायी फ़ाइल + नाम बदलना), इसलिए बिजली जाने पर आधी लिखी फ़ाइल नहीं बचती।

## सामान्य शॉर्टकट

| कार्रवाई            | Windows |
| ------------------- | ------- |
| नया दस्तावेज़       | ctrl+N  |
| खोलें               | ctrl+O  |
| सेव करें            | ctrl+S  |
| टैब बंद करें        | ctrl+W  |
| यह मैनुअल खोलें     | F1      |
| रिबन समेटें         | Ctrl+F1 |

**रिबन संक्षिप्त करना** हर एडिटर में काम करता है। टैब की पंक्ति बनी रहती है और उसके नीचे का कमांड बैंड छिप जाता है; चयनित टैब ही संक्षिप्त करने का नियंत्रण भी है, इसलिए जब तक रिबन संक्षिप्त है कोई टैब चयनित नहीं होता, और किसी भी टैब पर क्लिक करने से बैंड वापस आ जाता है। टैब पर डबल-क्लिक भी वही करता है। आपने इसे जिस हालत में छोड़ा, वह हर एडिटर के लिए अलग याद रहता है। Docs एक मध्यम घनत्व भी जोड़ता है: **⌥⌘K** / Ctrl+Alt+K पट्टी को केवल-आइकन से सिकोड़ देता है, वैसे ही याद रहता है।

हर एडिटर के भीतर के शॉर्टकट (format painter, find & replace, तालिका की कार्रवाइयाँ, ...) उनके अपने अध्यायों में हैं। Docs में एक खोजने योग्य कीबोर्ड-शॉर्टकट डायलॉग भी है (**ctrl+/**), जिसमें उसके सभी शॉर्टकट शामिल हैं।
