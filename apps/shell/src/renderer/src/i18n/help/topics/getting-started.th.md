# เริ่มต้นอย่างรวดเร็ว: ส่วนติดต่อผู้ใช้และพื้นฐานการใช้งาน

OfficeVega เป็นชุดโปรแกรมสำนักงานที่ทำงานบนเครื่องของคุณทั้งหมด: หน้าต่างเดียว แถบแท็บแถวเดียว และมีตัวแก้ไขหกตัว ได้แก่ Docs (ประมวลผลคำ), Sheets (สเปรดชีต), Slides (งานนำเสนอ), PDF, Markdown และ HTML ไฟล์ที่เปิดและบันทึกเป็น .docx / .xlsx / .pptx / .pdf เป็นไฟล์จริง ใช้งานร่วมกับ Word, Excel และ PowerPoint ได้อย่างสมบูรณ์ ไม่ต้องต่ออินเทอร์เน็ต

## ภาพรวมของส่วนติดต่อ

![หน้าแรก](img/home-screen.png)

หน้าต่างแบ่งออกเป็นสามส่วน:

- **แถบแท็บ (ด้านบน)**: ไฟล์ที่เปิดอยู่ทุกไฟล์จะเป็นหนึ่งแท็บ แท็บหน้าแรกทางซ้ายสุดมีอยู่เสมอและปิดไม่ได้ ส่วนแท็บอื่น ๆ คือเอกสารของคุณ ดับเบิลคลิกที่แท็บเพื่อเปลี่ยนชื่อไฟล์ได้ทันที
- **พื้นที่เนื้อหา**: ตัวแก้ไข (หรือหน้าแรก) ของแท็บที่กำลังใช้งาน
- **แถบเมนู**: อยู่ที่ด้านบนของหน้าต่างบน Windows เมนู ไฟล์ / แก้ไข / มุมมอง จะเปลี่ยนให้ตรงกับตัวแก้ไขที่กำลังใช้งาน

## การสร้างเอกสาร

เลือกวิธีใดวิธีหนึ่งต่อไปนี้:

- คลิกการ์ดสร้างด่วนในส่วน [เริ่มต้นอย่างรวดเร็ว](help://getting-started) ของ **หน้าแรก** (AI Docs, AI Sheets, AI Slides ฯลฯ)
- เมนู **ไฟล์ ▸ ใหม่**: Docs (ctrl+N), Sheets, Slides, Markdown, HTML หรือ PDF
- ลากไฟล์มาวางบนหน้าต่าง หรือดับเบิลคลิกไฟล์ในตัวจัดการไฟล์ของคุณ (หาก OfficeVega ตั้งเป็นแอปเริ่มต้น)

เอกสารใหม่จะเปิดขึ้นโดยยังไม่มีชื่อ และไฟล์บนดิสก์จะถูกสร้างเมื่อบันทึกครั้งแรกเท่านั้น

## การเปิดไฟล์

- เมนู **ไฟล์ ▸ เปิด…** (ctrl+O) จะเปิดตัวเลือกไฟล์ของระบบ รองรับ .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html
- คลิกรายการใดก็ได้ในรายการ **ล่าสุด** บนหน้าแรก
- คำสั่ง `officevega <file>` จากเทอร์มินัลก็ใช้เปิดไฟล์ได้เช่นกัน

## รูปแบบการบันทึก

- **บันทึกด้วยตนเอง**: ctrl+S หรือ ไฟล์ ▸ บันทึก / บันทึกเป็น การบันทึกครั้งแรกจะให้คุณเลือกตำแหน่งและชื่อไฟล์
- **บันทึกอัตโนมัติ** จะเปิดทำงานก็ต่อเมื่อคุณได้บันทึกไฟล์ด้วยตนเองอย่างน้อยหนึ่งครั้งแล้วเท่านั้น ไฟล์ PDF ที่คุณเปิดอ่านเฉย ๆ จะไม่ถูกเขียนทับโดยไม่ได้บอก บันทึกอัตโนมัติจะทำงานหลังจากเนื้อหาเปลี่ยนแปลงไปสักครู่
- เมื่อปิดแท็บที่มีการแก้ไขที่ยังไม่ได้บันทึก ระบบจะถามให้เลือก บันทึก / ไม่บันทึก / ยกเลิก ก่อน
- การเขียนไฟล์ทุกครั้งเป็นแบบอะตอมิก (เขียนลงไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ) ดังนั้นแม้ไฟดับกลางคันก็จะไม่เหลือไฟล์ที่เขียนค้างไว้ครึ่งเดียว

## แป้นพิมพ์ลัดที่ใช้บ่อย

| การทำงาน       | Windows   |
| -------------- | --------- |
| เอกสารใหม่     | ctrl+N    |
| เปิด           | ctrl+O    |
| บันทึก         | ctrl+S    |
| ปิดแท็บ        | ctrl+W    |
| เปิดคู่มือนี้  | F1        |
| ยุบ Ribbon     | Ctrl+F1   |

**การยุบ Ribbon** ใช้ได้ในทุกตัวแก้ไข แถวแท็บจะยังอยู่ที่เดิม ส่วนแถบคำสั่งด้านล่างจะถูกซ่อน แท็บที่เลือกอยู่ทำหน้าที่เป็นปุ่มยุบไปด้วย เพราะฉะนั้นตราบใดที่ Ribbon ยังยุบอยู่ จะไม่มีแท็บใดถูกเลือก และการกดแท็บใดก็ตามจะทำให้แถบคำสั่งกลับมา การดับเบิลคลิกแท็บก็ให้ผลเหมือนกัน ว่าคุณปิดหรือเปิดไว้ จะถูกจดจำแยกต่างหากสำหรับแต่ละตัวแก้ไข Docs เพิ่มความหนาแน่นระดับกลาง: **⌥⌘K** / Ctrl+Alt+K บีบแถบให้เหลือแต่ไอคอน และจดจำเช่นเดียวกัน

แป้นพิมพ์ลัดภายในแต่ละตัวแก้ไข (ตัวคัดลอกรูปแบบ, ค้นหาและแทนที่, การจัดการตาราง ฯลฯ) อยู่ในบทของแต่ละตัว นอกจากนี้ Docs ยังมีกล่องแป้นพิมพ์ลัดที่ค้นหาได้ (**ctrl+/**) ซึ่งครอบคลุมปุ่มลัดทั้งหมดของ Docs
