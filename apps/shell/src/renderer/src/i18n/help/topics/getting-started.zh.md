# 快速入门：界面与基本操作

OfficeVega 是一款完全在本机运行的办公套件：一个窗口、一排标签页，内含六个编辑器，分别是文档（Docs）、表格（Sheets）、幻灯片（Slides）、PDF、Markdown 和网页（HTML）。它读写的是真正的 .docx / .xlsx / .pptx / .pdf 文件，与 Word、Excel、PowerPoint 完全互通，无需联网。

## 界面总览

![主屏一览](img/home-screen.png)

窗口分为三个部分：

- **顶部标签条**：每个打开的文件都是一个标签页。最左边的「主页」标签始终存在，无法关闭；其余标签对应你打开的文档。双击标签可以直接重命名文件。
- **内容区**：当前标签对应的编辑器（或主页）。
- **菜单栏**：Windows 上位于窗口顶部。「文件」「编辑」「视图」等菜单会随当前编辑器自动切换。

## 新建文档

以下任选一种方式：

- 在**主页**的[快速开始](help://getting-started)区域点击对应的卡片（AI 文档、AI 表格、AI 幻灯片等）。
- 菜单 **文件 ▸ 新建**：Docs（ctrl+N）、表格、幻灯片、Markdown、网页或 PDF。
- 直接把文件拖进窗口，或双击系统里的文件（前提是 OfficeVega 已设为默认应用）。

新建的文档以「未命名」状态打开，第一次保存时才会在磁盘上创建文件。

## 打开文件

- 菜单 **文件 ▸ 打开**（ctrl+O）会弹出系统选择框，支持 .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html。
- 在主页的「最近使用」列表中直接点击即可打开。
- 在终端中运行 `officevega <文件>` 也可以打开文件。

## 保存方式

- **手动保存**：ctrl+S，或 文件 ▸ 保存 / 另存为。第一次保存时会让你选择位置和文件名。
- **自动保存**：只有在同一个文件上手动保存过**至少一次**之后才会开启。只读不改的 PDF 永远不会被悄悄改写。自动保存会在内容变更后稍作停顿时触发。
- 关闭有未保存改动的标签时，会先询问「保存 / 不保存 / 取消」。
- 所有写入都是原子操作（先写临时文件再重命名），即使中途断电也不会留下只写了一半的文件。

## 常用快捷键

| 操作       | Windows   |
| ---------- | --------- |
| 新建文档   | ctrl+N    |
| 打开       | ctrl+O    |
| 保存       | ctrl+S    |
| 关闭标签   | ctrl+W    |
| 打开本手册 | F1        |
| 折叠功能区 | Ctrl+F1   |

**折叠功能区**在每个编辑器里都可用：标签行保持不变，下方的命令条会收起。选中的标签同时充当折叠开关，所以功能区折叠期间不会有标签处于选中状态，点击任意标签即可让命令条重新出现。双击标签效果相同。折叠与否按编辑器分别记住。

各编辑器内部的快捷键（格式刷、查找替换、表格操作等）见对应章节。Docs 另外提供一个可搜索的快捷键对话框（**ctrl+/**），列出其全部组合键。
