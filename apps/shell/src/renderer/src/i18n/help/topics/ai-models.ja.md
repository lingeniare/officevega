# AI モデルと設定

## プロバイダーとモデル

モデルとキーは 設定（ホームの左下にあるアカウントの行）で構成します。

![設定ウィンドウ](img/settings-general.png)

- **VEGA のサーバー**：サインイン（デバイスコード方式）すれば、そのまま使えます。設定は不要です。リクエストは `https://api.vega.chat` に送られます。これは OpenRouter 互換のエンドポイントなので、OpenRouter 形式のクライアントはどれでも接続できます。
- **カスタムエンドポイント（BYOK）**：設定 ▸ AI で、プロトコルごとにベース URL と API キーを入力します。OpenAI 互換、Anthropic、Gemini、DeepSeek、DashScope（qwen）など。キーはこのマシンのアプリの設定ファイルに保存され、リクエストのヘッダーにだけ送出されます。
- 機能ごとに別のモデルを選べます：会話／生成、画像生成、画像解析。
- **接続テスト**：保存する前に、エンドポイントに到達できるか、モデルが見えるかを確認できます。
- ベース URL にはパスとクエリ文字列を含められます（ゲートウェイ形式）。エンドポイントのパスは正しく連結されます。

## モデルの選び方

- モデルの選択は AI パネルの上部と、設定 ▸ AI モデルにあります。チャット用に 1 つ選び、プロバイダーが対応していれば、画像生成と画像解析にもそれぞれ別のモデルを選べます。
- まずは既定の VEGA モデルで始めてください。ほとんどのオフィス作業（書き換え、表、数式、要約）に適しています。難しい推論や長い文書には大きなモデルへ、素早い下書きには小さく安価なモデルへ切り替えてください。
- 進行中の会話は、次の応答まで以前のモデルを使い続けます。新しいチャットは、すぐに新しい選択を使います。

## 料金と利用量

- VEGA の課金は、モデルごとの従量制です。料金表全体は [api.vega.chat/aimodels](https://api.vega.chat/aimodels) にあります。大きな作業の前に、モデルの入力／出力料金を確認してください。
- 現在の残高と利用料金は [VEGA ダッシュボード](https://api.vega.chat/dashboard) で確認できます。アカウントメニューの残高の行からも開けます。
- サインインしていない場合は、無料で使える組み込みのオプションだけが動作します。料金表のすべてのモデルを使うにはサインインしてください。

## CLI の連携（Codex 系）

- 設定で、ローカルの CLI プログラムのパスを指定できます（ASCII 以外のホームディレクトリや ~ の接頭辞も使え、~ は自動的に展開されます）。「モデルを検出」を押すと、その CLI が使えるモデルを調べます。
- 検証はパスが存在するかどうかだけを確認します。文字セットの制限はありません。

## 変更が反映されるタイミング

- モデルとエンドポイントの変更は、すぐに反映されます。進行中の会話は、次の応答まで古い設定を使い続けます。
