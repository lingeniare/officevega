# התחלה מהירה: הממשק והבסיס

OfficeVega היא חבילת משרד שפועלת כולה על המחשב שלכם: חלון אחד, שורת כרטיסיות אחת, ובתוכה שישה עורכים — Docs (עיבוד תמלילים), Sheets (גליונות אלקטרוניים), Slides (מצגות), PDF, Markdown ו-HTML. הקבצים הם קבצי .docx / .xlsx / .pptx / .pdf אמיתיים, שניתנים להחלפה מלאה עם Word, Excel ו-PowerPoint. אין צורך ברשת.

## סקירת הממשק

![מסך הבית](img/home-screen.png)

החלון מורכב משלושה חלקים:

- **שורת הכרטיסיות (למעלה)**: כל קובץ פתוח הוא כרטיסייה. כרטיסיית הבית שבקצה השמאלי קיימת תמיד ואי אפשר לסגור אותה; שאר הכרטיסיות הן המסמכים שלכם. לחיצה כפולה על כרטיסייה משנה את שם הקובץ שלה במקום.
- **אזור התוכן**: העורך (או הבית) ששייך לכרטיסייה הפעילה.
- **שורת התפריטים**: בחלק העליון של החלון ב-Windows. תפריטי File / Edit / View מתעדכנים לפי העורך הפעיל.

## יצירת מסמך

בחרו אחת מהאפשרויות:

- לחצו על כרטיסיית יצירה מהירה בקטע [התחלה מהירה](help://getting-started) של **הבית** (AI Docs, AI Sheets, AI Slides, ...).
- מתפריט **File ▸ New**: Docs (ctrl+N), Sheets, Slides, Markdown, HTML או PDF.
- גררו קובץ אל החלון, או לחצו עליו פעמיים במנהל הקבצים שלכם (אם OfficeVega היא ברירת המחדל).

מסמך חדש נפתח ללא שם; הקובץ על הדיסק נוצר רק בשמירה הראשונה.

## פתיחת קבצים

- מתפריט **File ▸ Open** (ctrl+O) נפתח בורר הקבצים של המערכת: .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html.
- לחצו על כל פריט ברשימת **האחרונים** שבבית.
- הפקודה `officevega <file>` מהטרמינל פותחת קבצים גם כן.

## מודל השמירה

- **שמירה ידנית**: ctrl+S, או File ▸ Save / Save As. בשמירה הראשונה האפליקציה תבקש מיקום ושם.
- **שמירה אוטומטית** נדלקת רק אחרי ששמרתם את הקובץ ידנית לפחות פעם אחת — קובץ PDF שרק קראתם לעולם לא ייכתב מחדש בשקט. השמירה האוטומטית פועלת זמן קצר אחרי שהתוכן משתנה.
- סגירת כרטיסייה עם שינויים שלא נשמרו שואלת קודם: Save / Discard / Cancel.
- כל כתיבה מתבצעת באופן אטומי (קובץ זמני + שינוי שם), כך שניתוק חשמל לא ישאיר קובץ חצי כתוב.

## קיצורי מקלדת נפוצים

| פעולה               | Windows |
| ------------------- | ------- |
| מסמך חדש            | ctrl+N  |
| פתיחה               | ctrl+O  |
| שמירה               | ctrl+S  |
| סגירת כרטיסייה      | ctrl+W  |
| פתיחת מדריך זה      | F1      |
| כיווץ הסרגל         | Ctrl+F1 |

**כיווץ הסרגל** פועל בכל העורכים. שורת הכרטיסיות נשארת, ורצועת הפקודות שמתחתיה מוסתרת; הכרטיסייה הנבחרת משמשת גם כפקד הכיווץ, ולכן כל עוד הסרגל מכווץ אין כרטיסייה נבחרת, ולחיצה על כל כרטיסייה מחזירה את הסרגל. לחיצה כפולה על כרטיסייה עושה את אותו הדבר. הבחירה איך השארתם את הסרגל נזכרת לכל עורך בנפרד.

קיצורי המקלדת בתוך כל עורך (מברשת עיצוב, חיפוש והחלפה, פעולות על טבלאות, ...) מפורטים בפרקים שלהם. בנוסף, ל-Docs יש חלון קיצורי מקלדת עם חיפוש (**ctrl+/**) שמכסה את הקיצורים שלו במלואם.
