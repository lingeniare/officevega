# 빠른 시작: 화면 구성과 기본 사용법

OfficeVega는 전적으로 내 컴퓨터에서 실행되는 오피스 제품군입니다. 창 하나와 탭 한 줄에 여섯 개의 편집기가 들어 있습니다. 문서(Docs), 스프레드시트(Sheets), 프레젠테이션(Slides), PDF, Markdown, HTML입니다. 파일은 실제 .docx / .xlsx / .pptx / .pdf이므로 Word, Excel, PowerPoint와 그대로 주고받을 수 있습니다. 인터넷 연결은 필요 없습니다.

## 화면 개요

![홈 화면](img/home-screen.png)

창은 세 부분으로 나뉩니다:

- **탭 줄(위쪽)**: 열린 파일마다 탭이 하나씩 생깁니다. 가장 왼쪽의 홈 탭은 항상 있으며 닫을 수 없습니다. 나머지 탭은 여러분의 문서입니다. 탭을 더블클릭하면 파일 이름을 그 자리에서 바꿀 수 있습니다.
- **내용 영역**: 활성 탭에 해당하는 편집기(또는 홈)입니다.
- **메뉴 막대**: Windows에서는 창 맨 위에 있습니다. 파일/편집/보기 메뉴는 활성 편집기에 맞춰 바뀝니다.

## 문서 만들기

다음 중 아무 방법이나 쓸 수 있습니다:

- **홈**의 [빠른 시작](help://getting-started) 영역에서 빠른 생성 카드(AI Docs, AI Sheets, AI Slides 등)를 누릅니다.
- 메뉴 **파일 ▸ 새로 만들기**: Docs(ctrl+N), Sheets, Slides, Markdown, HTML 또는 PDF.
- 파일을 창으로 끌어다 놓거나, 파일 관리자에서 더블클릭합니다(OfficeVega가 기본 앱인 경우).

새 문서는 제목 없이 열리며, 디스크에 파일은 처음 저장할 때 만들어집니다.

## 파일 열기

- 메뉴 **파일 ▸ 열기**(ctrl+O)를 누르면 시스템 파일 선택 창이 열립니다: .docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html.
- 홈의 **최근 항목** 목록에서 아무거나 누릅니다.
- 터미널에서 `officevega <file>`을 실행해도 파일을 열 수 있습니다.

## 저장 방식

- **수동 저장**: ctrl+S 또는 파일 ▸ 저장 / 다른 이름으로 저장. 처음 저장할 때는 위치와 이름을 묻습니다.
- **자동 저장**은 파일을 수동으로 한 번 이상 저장한 뒤에만 켜집니다. 읽기만 한 PDF가 몰래 덮어써지는 일은 없습니다. 자동 저장은 내용을 바꾸고 조금 뒤에 실행됩니다.
- 저장하지 않은 변경 사항이 있는 탭을 닫으면 먼저 저장 / 저장 안 함 / 취소를 묻습니다.
- 모든 쓰기는 원자적으로 이루어집니다(임시 파일 + 이름 변경). 그래서 갑자기 전원이 꺼져도 파일이 절반만 저장되지 않습니다.

## 자주 쓰는 단축키

| 동작           | Windows   |
| -------------- | --------- |
| 새 문서        | ctrl+N    |
| 열기           | ctrl+O    |
| 저장           | ctrl+S    |
| 탭 닫기        | ctrl+W    |
| 이 매뉴얼 열기 | F1        |
| 리본 접기      | Ctrl+F1   |

**리본 축소**는 모든 편집기에서 동작합니다. 탭 행은 그대로 두고 그 아래 명령 밴드만 숨겨집니다. 선택된 탭이 축소 조작까지 겸하므로, 리본이 축소된 동안에는 선택된 탭이 없고 어떤 탭을 눌러도 밴드가 다시 나타납니다. 탭을 두 번 클릭해도 같습니다. 어느 쪽으로 남겨 두었는지는 편집기마다 따로 기억됩니다. Docs에는 중간 밀도도 있습니다: **⌥⌘K** / Ctrl+Alt+K로 명령 띠를 아이콘만으로 압축할 수 있고, 마찬가지로 기억됩니다.

각 편집기 안의 단축키(서식 복사, 찾기 및 바꾸기, 표 작업 등)는 해당 장에 있습니다. Docs에는 자체 단축키를 모두 담은 검색 가능한 키보드 단축키 대화상자(**ctrl+/**)도 있습니다.
