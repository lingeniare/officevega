# AI 模型与设置

## 服务商与模型

模型和密钥在设置中配置（点击主屏左下角的账户行即可打开）：

![设置窗口](img/settings-general.png)

- **VEGA 官方服务器**：登录（设备码流程）后即可直接使用，无需任何配置。请求会发送到 `https://api.vega.chat`，这是一个与 OpenRouter 兼容的端点，因此任何 OpenRouter 风格的客户端都可以将地址指向它。
- **自定义端点（BYOK）**：在 设置 ▸ AI 中，为每种协议填写基础 URL 和 API key。支持 OpenAI 兼容接口、Anthropic、Gemini、DeepSeek、DashScope（qwen）等。密钥保存在本机的应用设置文件中，发送时仅放在请求头里。
- 每类能力都可以选择不同的模型：对话/生成、图像生成、图像理解（看图）。
- **连接测试**：保存之前，可以测试端点是否连通以及模型是否可见。
- 基础 URL 可以包含路径和查询字符串（例如网关地址），应用会正确拼接端点路径。

## 选择模型

- 模型选择器位于 AI 面板顶部，也位于 设置 ▸ AI 模型 中。对话使用一个选项；如果服务商支持，图像生成和图像理解可以分别选择各自的模型。
- 建议先使用默认的 VEGA 模型，它适合大多数办公任务（改写、表格、公式、摘要）。处理复杂推理或长文档时，可以换成更大的模型；需要快速起草时，可以换成更小、更便宜的模型。
- 正在进行的对话会保留旧模型，直到下一轮；新对话会立即使用你新选的模型。

## 价格与用量

- VEGA 按模型按量计费。完整价格表位于 [api.vega.chat/aimodels](https://api.vega.chat/aimodels)，在开始大型任务之前，请先查看模型的输入/输出价格。
- 当前余额和消费情况可在 [VEGA 控制台](https://api.vega.chat/dashboard)查看，也可以从账户菜单的余额行打开。
- 未登录时，只有免费的内置选项可以使用；登录后即可解锁价格表中的全部模型。

## CLI 集成（Codex 类）

- 设置中可以指定本机 CLI 程序的路径（支持非 ASCII 字符的用户目录，以及 ~ 前缀，~ 会自动展开）；「检测模型」会探测该 CLI 可用的模型。
- 路径校验只检查文件是否存在，不限制字符集。

## 何时生效

- 模型和端点的修改会立即生效；正在进行的对话会继续使用旧配置，直到下一轮。
