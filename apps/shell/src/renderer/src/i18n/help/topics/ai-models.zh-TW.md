# AI 模型與設定

## 服務商與模型

模型與金鑰在設定中配置（點選首頁左下角的帳戶列即可開啟）：

![設定視窗](img/settings-general.png)

- **VEGA 官方伺服器**：登入（裝置碼流程）即可使用，完全免設定。請求會送到 `https://api.vega.chat`，這是一個與 OpenRouter 相容的端點，因此任何 OpenRouter 風格的用戶端都可以把位址指向它。
- **自訂端點（BYOK）**：設定 ▸ AI 中可依協定填寫 Base URL 與 API 金鑰——OpenAI 相容、Anthropic、Gemini、DeepSeek、DashScope（qwen）等。金鑰儲存在本機的應用程式設定檔中，傳送時只放在請求標頭裡。 Atlas Cloud 也在內建協定之列。
- 不同能力可以分別挑選模型：對話／生成、圖像生成、圖像分析。
- **測試連線**：在儲存前，先確認端點可以連線、模型是否可見。
- Base URL 可以包含路徑與查詢字串（閘道形式）；端點路徑會正確地接在其後。

## 選擇模型

- 模型選擇器位於 AI 面板頂端，也位於 設定 ▸ AI 模型 中。對話使用一個選項；若服務商支援，圖像生成與圖像分析可以分別選擇各自的模型。
- 建議先使用預設的 VEGA 模型，它適合大多數辦公任務（改寫、表格、公式、摘要）。處理複雜推理或長文件時，可以換成較大的模型；需要快速草稿時，則換成較小、較便宜的模型。
- 進行中的對話會沿用舊模型，直到下一輪；新對話會立即使用你新選的模型。

## 價格與用量

- VEGA 採按模型計費的隨用隨付方式。完整價格表位於 [api.vega.chat/aimodels](https://api.vega.chat/aimodels)。在進行大型任務前，請先查看模型的輸入與輸出價格。
- 目前的餘額與消費紀錄可在 [VEGA 儀表板](https://api.vega.chat/dashboard)查看，也可以從帳戶選單的餘額列開啟。
- 未登入時，只能使用免費的內建選項；登入後即可解鎖價格表上的所有模型。

## CLI 整合（Codex 類）

- 設定中可指定本機 CLI 程式的路徑（支援非 ASCII 的家目錄與 ~ 前綴，~ 會自動展開）；「偵測模型」會探測該 CLI 可用的模型。
- 路徑驗證只檢查是否存在，不限制字元集。

## 變更何時生效

- 模型與端點的變更會立即生效；進行中的對話會沿用舊的設定，直到它的下一輪為止。
