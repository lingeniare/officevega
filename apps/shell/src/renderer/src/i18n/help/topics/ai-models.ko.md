# AI 모델과 설정

## 제공자와 모델

모델과 키는 설정에서 구성합니다(홈 왼쪽 아래의 계정 행):

![설정 창](img/settings-general.png)

- **VEGA 서버 제공 모델**: 로그인(기기 코드 방식)만 하면 바로 사용할 수 있으며 별도 설정이 필요 없습니다. 요청은 `https://api.vega.chat`으로 전송됩니다. 이 주소는 OpenRouter 호환 엔드포인트이므로, OpenRouter 방식의 클라이언트라면 무엇이든 이 주소를 가리키게 할 수 있습니다.
- **사용자 지정 엔드포인트(BYOK)**: 설정 ▸ AI에서 프로토콜마다 기본 URL과 API 키를 입력합니다. OpenAI 호환, Anthropic, Gemini, DeepSeek, DashScope(qwen) 등을 지원합니다. 키는 이 컴퓨터의 앱 설정 파일에 저장되며, 요청 헤더로만 전송됩니다.
- 기능별로 다른 모델을 고를 수 있습니다: 대화/생성, 이미지 생성, 이미지 분석.
- **연결 테스트**: 저장하기 전에 엔드포인트 접속 가능 여부와 모델 표시 여부를 확인합니다.
- 기본 URL에는 경로와 쿼리 문자열이 포함될 수 있습니다(게이트웨이 방식). 엔드포인트 경로는 올바르게 덧붙여집니다.

## 모델 고르기

- 모델 선택기는 AI 패널 위쪽과 설정 ▸ AI 모델에 있습니다. 대화용으로 하나를 고르고, 제공자가 지원하는 경우 이미지 생성과 이미지 분석용을 따로 고를 수 있습니다.
- 기본 VEGA 모델로 시작하세요. 대부분의 사무 작업(다시 쓰기, 표, 수식, 요약)에 적합합니다. 어려운 추론이나 긴 문서에는 더 큰 모델로, 빠른 초안에는 작고 저렴한 모델로 바꾸세요.
- 진행 중인 대화는 다음 응답 전까지 이전 모델을 유지합니다. 새 대화는 바로 새로 고른 모델을 사용합니다.

## 요금과 사용량

- VEGA 요금은 모델별 종량제입니다. 전체 요금표는 [api.vega.chat/aimodels](https://api.vega.chat/aimodels)에 있습니다. 큰 작업을 하기 전에 모델의 입력/출력 요금을 확인하세요.
- 현재 잔액과 사용 금액은 [VEGA 대시보드](https://api.vega.chat/dashboard)에서 볼 수 있으며, 계정 메뉴의 잔액 행에서도 열 수 있습니다.
- 기본 URL에는 경로와 쿼리 문자열을 넣을 수 있어(게이트웨이 형식) 엔드포인트 경로가 올바르게 이어 붙습니다.

## CLI 연동(Codex 계열)

- 설정에서 로컬 CLI 프로그램 경로를 입력할 수 있습니다(ASCII가 아닌 홈 디렉터리와 ~ 접두사도 동작하며, ~는 자동으로 펼쳐집니다). **모델 감지**는 CLI에서 사용할 수 있는 모델을 확인합니다.
- 검증은 경로가 존재하는지만 확인합니다. 문자 집합 제한은 없습니다.

## 변경 사항이 적용되는 시점

- 모델과 엔드포인트 변경은 즉시 적용됩니다. 진행 중인 대화는 다음 응답 전까지 이전 설정을 유지합니다.
