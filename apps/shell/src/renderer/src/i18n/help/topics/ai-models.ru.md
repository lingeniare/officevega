# Модели ИИ и настройки

## Провайдеры и модели

Модели и ключи настраиваются в Настройках (строка аккаунта в левом нижнем углу «Главной»):

![Окно настроек](img/settings-general.png)

- **ВЕГА на своих серверах**: войдите (схема с кодом устройства) и пользуйтесь — настройки не нужны. Запросы идут на `https://api.vega.chat` — это endpoint, совместимый с OpenRouter, поэтому к нему можно подключить любой клиент в стиле OpenRouter.
- **Собственные адреса (BYOK)**: в Настройки ▸ ИИ указывается базовый URL и API-ключ для каждого протокола — совместимый с OpenAI, Anthropic, Gemini, DeepSeek, DashScope (qwen) и другие. Ключи сохраняются в файле настроек приложения на этом компьютере и отправляются только в заголовках запросов.
- Для каждой способности можно выбрать свою модель: общение и генерация, создание изображений, анализ изображений.
- **Проверить подключение**: убеждается, что адрес доступен и модель видна, до сохранения.
- Базовый URL может содержать путь и строку запроса (в стиле шлюза); путь конечной точки добавляется корректно.

## Выбор модели

- Переключатель модели — вверху панели ИИ и в Настройки ▸ Модель ИИ: один выбор для общения, плюс отдельные для генерации изображений и анализа изображений, если провайдер их поддерживает.
- Начните с модели ВЕГА по умолчанию: её хватает для большинства офисных задач (переписать, таблицы, формулы, выжимки). Для сложного рассуждения или длинных документов возьмите модель покрупнее, а для быстрых черновиков — маленькую и дешёвую.
- Уже идущий разговор продолжает использовать прежнюю модель до следующего захода; новые чаты сразу берут новый выбор.

## Цены и использование

- Оплата ВЕГА — по факту использования, у каждой модели свой тариф. Полный прайс — на [api.vega.chat/aimodels](https://api.vega.chat/aimodels): перед большой задачей посмотрите цену входа/выхода модели.
- Баланс и расходы — на [панели ВЕГА](https://api.vega.chat/dashboard), она же открывается из строки баланса в меню аккаунта.
- Без входа доступны только бесплатные встроенные варианты; войдите, чтобы открыть все модели из прайса.

## Интеграция с CLI (в духе Codex)

- В настройках указывается путь к локальной программе CLI (домашние каталоги с не-ASCII именами и префикс ~ работают; ~ разворачивается автоматически); «Автоопределение» опрашивает у CLI доступные модели.
- Проверка смотрит только на существование файла — никаких ограничений по набору символов.

## Когда изменения вступают в силу

- Смена модели и адреса применяется сразу; уже идущий разговор продолжает использовать прежнюю конфигурацию до следующего захода.
