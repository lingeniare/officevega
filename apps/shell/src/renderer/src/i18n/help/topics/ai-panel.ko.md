# AI 어시스턴트 패널

모든 편집기에서 AI 패널을 불러올 수 있습니다. 무언가를 선택하고 지시를 내리면, 결과가 실시간으로 스트리밍되는 것을 볼 수 있습니다.

## 열기와 사용법

![Docs의 AI 패널](img/ai-panel.png)

- 시작 방법: 각 편집기 리본의 **AI 버튼**, 컨텍스트 메뉴의 **AI에게 묻기**, 또는 표시 막대의 AI에게 묻기.
- 작업을 쉬운 말로 설명하고(이것을 다시 쓰기 / 이 열을 백분율로 / 이 페이지 레이아웃 바꾸기...) Enter를 누릅니다.
- 답변은 **스트리밍**으로 표시됩니다. AI에 도구가 필요하면(문서 읽기, 편집하기) 그 도구를 실행하고 끝날 때까지 계속 진행합니다.
- **중지**: 언제든지 현재 응답을 중단할 수 있습니다.

## 할 수 있는 일

- **Docs**: 다시 쓰기, 늘리기, 번역, 요약, 표와 그림 삽입, 서식 조정. 매번 응답하기 전에 먼저 스냅샷을 남깁니다.
- **Sheets**: 수식, 데이터 채우기, 일괄 변환, 서식.
- **Slides**: 슬라이드 전체 생성, 레이아웃 조정, 문구 다시 쓰기.
- **PDF**: 선택한 텍스트나 페이지를 기준으로 한 질의응답과 요약.
- **Markdown / HTML**: 다시 쓰기, 확장, 번역.

## 대화 기록

- 모든 대화는 자동으로 저장되며 이 컴퓨터에만 남습니다. 내일 패널을 다시 열면 하던 자리에서 이어서 할 수 있습니다.
- **새 대화**로 새 채팅을 시작하고, 패널 위쪽의 기록 목록에서 지난 대화로 전환합니다.
- 대화 이름을 바꾸면 찾기 쉽고, 삭제하면 완전히 지워집니다. 대화를 삭제해도 문서는 전혀 건드리지 않습니다.

## 되돌리기와 안전

- Docs 패널에는 **버전 목록**이 있습니다. 응답마다 스냅샷 하나가 생기며, 어느 것으로든 되돌릴 수 있고, 되돌리기 자체도 Ctrl+Z로 취소할 수 있습니다. 스냅샷은 문서를 다시 열어도 유지됩니다.
- AI의 편집도 직접 편집과 같은 편집 과정을 거칩니다(실행 취소 가능, 저장 확인 대상). 저장 확인을 건너뛰는 것은 없습니다.

## 개인정보와 익명화

- 지시 내용과 관련 문서 내용은 **사용자가 설정한 모델 서비스**(VEGA 호스팅 또는 사용자 지정 엔드포인트, 다음 장 참고)로 전송됩니다. 설정이 없으면 아무것도 전송되지 않습니다.
- **익명화(152-FZ)**: 전송 전에 앱이 이름, 전화번호, 이메일, 여권 정보 같은 개인 정보를 가릴 수 있어, 모델은 이를 보지 못합니다. 설정 ▸ AI에서 켜세요. 가려진 부분은 응답이 돌아오면 문서에 자동으로 복원됩니다.
- **추적 분석 없음**: OfficeVega에는 Google Analytics나 제3자 추적 도구가 들어 있지 않습니다. 끌 것이 없으므로 사용 통계 스위치도 없습니다. 문서와 대화 내용은 사용자가 설정한 경로 밖으로 나가지 않습니다.
- 로컬 파일은 다른 곳에 업로드되지 않습니다. BYOK 키는 이 컴퓨터의 앱 설정 파일에 저장되며, 요청 헤더로만 전송됩니다.
