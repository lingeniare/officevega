# クイックスタート：画面と基本操作

OfficeVega は、お使いのマシン上で完結するオフィススイートです。ウィンドウは 1 つで、タブが 1 列に並び、その中に 6 種類のエディターがあります。Docs（文書）、Sheets（表計算）、Slides（プレゼンテーション）、PDF、Markdown、HTML です。扱うファイルは本物の .docx / .xlsx / .pptx / .pdf なので、Word、Excel、PowerPoint と完全にやり取りできます。ネットワーク接続は不要です。

## 画面の全体像

![ホーム画面](img/home-screen.png)

ウィンドウは 3 つの部分に分かれています。

- **タブバー（上）**：開いているファイルがそれぞれ 1 つのタブになります。一番左のホームタブは常に表示され、閉じることはできません。残りのタブが開いている文書です。タブをダブルクリックすると、そのファイル名をその場で変更できます。
- **コンテンツエリア**：アクティブなタブに対応するエディター（またはホーム）です。
- **メニューバー**：Windows ではウィンドウ上部にあります。ファイル／編集／表示の各メニューは、アクティブなエディターに合わせて内容が変わります。

## 文書を作る

次のいずれかの方法で作成できます。

- **ホーム**の[クイックスタート](help://getting-started)欄にあるクイック作成カード（AI Docs、AI Sheets、AI Slides など）をクリックする。
- メニュー **ファイル ▸ 新規作成**：Docs（ctrl+N）、Sheets、Slides、Markdown、HTML、PDF。
- ファイルをウィンドウにドラッグする。またはファイルマネージャーでダブルクリックする（OfficeVega が既定のアプリになっている場合）。

新しい文書は「無題」の状態で開き、ディスク上のファイルは最初に保存したときに作られます。

## ファイルを開く

- メニュー **ファイル ▸ 開く**（ctrl+O）で、システムのファイル選択ダイアログが開きます。.docx / .doc / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html に対応しています。
- ホームの**最近使ったファイル**リストから任意の項目をクリックする。
- ターミナルで `officevega <file>` と入力しても開けます。

## 保存の仕組み

- **手動保存**：ctrl+S、または ファイル ▸ 保存／名前を付けて保存。最初の保存では、保存先とファイル名を尋ねられます。
- **自動保存**は、同じファイルを一度でも手動で保存した後にだけ有効になります。読み取るだけの PDF が黙って書き換えられることはありません。自動保存は内容を変更してから少し後に実行されます。
- 未保存の変更があるタブを閉じようとすると、保存／破棄／キャンセルのどれにするかを先に尋ねられます。
- 書き込みはすべてアトミックに行われます（一時ファイルに書いてから名前を変更）。そのため、停電しても中途半端なファイルが残ることはありません。

## よく使うショートカット

| 操作                 | Windows |
| -------------------- | ------- |
| 新規文書             | ctrl+N  |
| 開く                 | ctrl+O  |
| 保存                 | ctrl+S  |
| タブを閉じる         | ctrl+W  |
| このマニュアルを開く | F1      |
| リボンを折りたたむ   | Ctrl+F1 |

**リボンの折りたたみ**はすべてのエディターで使えます。タブの行はそのまま残され、その下のコマンドバンドだけが隠れます。選択中のタブが折りたたみの操作も兼ねるので、リボンが折りたたまれている間はタブが選択されておらず、どのタブを押してもバンドが戻ります。タブをダブルクリックしても同じです。どちらの状態に残したかはエディターごとに記憶されます。 Docs には中間の密度もあります：**⌥⌘K** / Ctrl+Alt+K でコマンド帯をアイコンのみに圧縮でき、同じように記憶されます。

各エディター内のショートカット（書式のコピー、検索と置換、表の操作など）は、それぞれの章で説明しています。Docs には、検索できるキーボードショートカットの一覧ダイアログ（**ctrl+/**）もあり、Docs のすべての組み合わせを網羅しています。
