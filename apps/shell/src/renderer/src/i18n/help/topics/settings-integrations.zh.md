# 设置、语言、主题与 MCP 集成

## 打开设置

点击主屏左下角的账户行即可打开设置面板（未登录时显示为「登录」）。面板共分六个部分：账户、AI 模型、AI 生图与搜索、通用、集成、关于。

![设置 ▸ 通用：语言、主题与自动保存都在这里](img/settings-general.png)

AI 模型的配置另有专门一章。**AI 生图与搜索**是按服务商分别开启图像生成、图像理解、视频分析、网络搜索和本机文件搜索的地方。

## 语言

- 设置中可选择 **21 种界面语言**：英语、简体中文、日语、韩语、法语、德语、西班牙语、泰语、印尼语、俄语、阿拉伯语、葡萄牙语、意大利语、波兰语、捷克语、荷兰语、马来语、希伯来语、印地语、繁体中文、越南语。
- 切换后立即生效并保存；菜单栏会随语言重新生成。

## 主题

提供浅色 / 深色 / 跟随系统三种模式。选择「跟随系统」时，会随操作系统外观自动切换，编辑器区域同步换肤，不会出现闪白。

## 通用

- **匿名发送使用统计**：默认开启。使用 Google Analytics 4，会发送你的公网 IP 地址和传输元数据；文档内容和文件名绝不会被收集，每个事件只包含一种类型，例如「打开了一个 .docx」。你随时可以在这里关闭。
- **AI 侧边栏位置**（左侧或右侧）、**AI 面板文字大小**，以及 **AI 对话拼写检查**。
- **在新文档中打开 AI 面板**：关闭时，新文档启动后面板是收起的，点一下即可展开。
- **自动保存所有文档**会在每个编辑器中默认开启自动保存；你仍然可以针对单个窗口将其关闭。
- **默认保存位置**配合**更改**按钮，以及**设为 Office 文档的默认程序**，可以将 .docx / .xlsx / .pptx 交由 OfficeVega 打开。

## AI 生图与搜索

这些不是开关。每项能力各自选择提供服务的服务商，服务商的密钥和基础地址只需填写一次，之后各行共用：

- **网络搜索**、**生图**、**图片解析**和**视频解析**，每一项都有服务商、模型、密钥和基础地址。选择 **VEGA** 作为服务商，即可凭你的登录密钥通过 `api.vega.chat` 进行调用。
- **本机文件搜索**跑在这台机器上。它下面的 **Jev 搜索重排** 默认关闭。打开后，本机搜索前 20 条命中的片段——每份文档最多 1,200 个字符，外加文件名和文件夹名——会发给你选择的决策端点（VEGA, OpenRouter 或 TypeSafe 的 Jev、Perplexity、Liquid AI d1、Cloudflare、本地引擎或自定义 URL），按相关性重新排序。关闭时不会有任何东西离开本机。

## 关于

- **版本**信息、项目网站 [officevega.com](https://officevega.com)，以及发布页 [officevega.com/releases](https://officevega.com/releases)。
- **更新通道**：稳定版或 Beta 版。修改后立即生效并检查更新；它不会把 Beta 版安装降级回稳定版。

## 默认应用绑定

设置中可以将 .docx / .xlsx / .pptx / .pdf 等格式关联为由 OfficeVega 打开（这会写入系统级的默认应用注册，请按平台提示进行确认）。

## 第三方声明与更新

- 帮助菜单 ▸ 第三方软件声明：随应用附带的完整开源许可证清单。
- 帮助菜单 ▸ 检查更新：手动触发一次更新检查；如有新版本，会提示安装。

## VEGA 登录

- 设置或云端项目列表中的登录入口使用**设备码**流程：OfficeVega 会显示验证码并在浏览器中打开登录页面，完成后自动继续。
- 登录仅用于：云端项目列表，以及 `api.vega.chat` 上的 VEGA 官方托管模型。未登录时，所有本地功能和自定义模型依然完全可用。
- 退出登录在设置中一键完成。

## MCP 集成（面向高级用户 / AI 客户端）

**集成**是将 OfficeVega 连接到编程代理的面板，它也有专门一章：连接编程代理。简单来说：选择一种连接方式（命令行或 MCP），按照对应小节操作，然后新开一个对话直接提问即可。

![设置 ▸ 集成：先是三个步骤，然后是技能行和 MCP 选项](img/settings-integrations.png)

在**本地 HTTP 服务器**下，应用可以自行运行该服务器，包括一个启用开关和一个端口。**高级**选项还会添加健康检查网址和日志文件。它只监听 localhost。

## 命令行速查

| 命令               | 作用                |
| ------------------ | ------------------- |
| `officevega <file>` | 打开文件            |
| `officevega mcp`    | 启动本机 MCP 服务器 |
| `officevega --help` | 全部命令与参数      |
