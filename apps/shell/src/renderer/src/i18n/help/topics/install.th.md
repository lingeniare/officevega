# การติดตั้ง OfficeVega

ทุกบิลด์ถูกเผยแพร่ไว้ที่ [หน้าเผยแพร่](https://officevega.com/releases) ทุกบิลด์มาจาก `main` และตัวติดตั้งสำหรับ Windows มีลายเซ็นกำกับ

## เลือกไฟล์ให้ตรงกับเครื่องของคุณ

| แพลตฟอร์ม                            | ข้อกำหนด                                              | ไฟล์                    |
| ------------------------------------ | ----------------------------------------------------- | ----------------------- |
| **Windows** — คอมพิวเตอร์ส่วนใหญ่    | Windows 10+, Intel/AMD                                | ตัวติดตั้ง `-x64.exe`   |
| **Windows** บน Arm                   | Windows 11 บน Arm (Snapdragon X และรุ่นใกล้เคียง)     | ตัวติดตั้ง `-arm64.exe` |

## บน Windows

รันตัวติดตั้ง `.exe` ตัวติดตั้งจะวาง OfficeVega ไว้ในเมนู Start และลงทะเบียน `.docx`, `.xlsx`, `.pptx`, `.pdf` และไฟล์อื่น ๆ ให้เป็นค่าเริ่มต้น ดังนั้นดับเบิลคลิกที่ไฟล์ก็จะเปิดได้ทันที

## บิลด์ที่คุณกำลังใช้งาน

**การตั้งค่า ▸ เกี่ยวกับ** คือที่ที่แอปแสดงว่าคุณใช้บิลด์ไหน ติดตามช่องทางการอัปเดตใด และโปรเจกต์อยู่ที่ไหน เมื่อมีบิลด์ใหม่กว่าเผยแพร่บนช่องทางนั้น แผงเดียวกันจะเสนอให้อัปเดต

## คำสั่งบรรทัดคำสั่งมาให้ด้วย

ทุกการติดตั้งมาพร้อมคำสั่ง `officevega` ที่ทำงานกับเอนจินตัวเดียวกับหน้าต่างของแอป ทั้งสองส่วนจึงไม่มีทางให้ผลต่างกันกับไฟล์เดียวกัน คำสั่งนี้อยู่ภายในแพ็กเกจของแอป บน macOS และ Windows ให้รัน `officevega install-cli` เพื่อเพิ่มคำสั่งลงใน `PATH` ของคุณ ดู **คำสั่งบรรทัดคำสั่งและเอเจนต์** เพื่อดูว่าคำสั่งนี้ทำอะไรได้บ้าง
