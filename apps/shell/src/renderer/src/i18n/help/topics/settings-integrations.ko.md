# 설정, 언어, 테마, MCP 연동

## 설정 열기

홈 왼쪽 아래의 계정 행을 누르면 설정 패널이 열립니다(로그아웃 상태에서는 '로그인'으로 표시됩니다). 패널에는 여섯 개의 섹션이 있습니다: 계정, AI 모델, AI 미디어 및 검색, 일반, 연동, 정보.

![설정 ▸ 일반: 언어, 테마, 자동 저장이 있는 곳](img/settings-general.png)

AI 모델 설정은 별도 문서에 있습니다. **AI 미디어 및 검색**에서는 제공자별로 이미지 생성, 이미지 분석, 동영상 분석, 웹 검색, 로컬 파일 검색을 켭니다.

## 언어

- 설정에서 **21개의 UI 언어**를 고를 수 있습니다: 영어, 중국어(간체), 일본어, 한국어, 프랑스어, 독일어, 스페인어, 태국어, 인도네시아어, 러시아어, 아랍어, 포르투갈어, 이탈리아어, 폴란드어, 체코어, 네덜란드어, 말레이어, 히브리어, 힌디어, 중국어(번체), 베트남어.
- 언어를 바꾸면 바로 적용되고 그대로 유지됩니다. 기본 메뉴 막대도 그 언어로 다시 만들어집니다.

## 테마

밝게 / 어둡게 / 시스템 설정. 시스템을 고르면 OS 화면 모드를 따르며, 편집기도 깜빡임 없이 함께 바뀝니다. 같은 스위치로 AI 패널과 홈 화면 색도 바뀌므로 앱 전체가 하나의 디자인을 유지합니다. 밝은 곳에서는 밝게, 밤 작업에는 어둡게, Windows 설정을 따르려면 시스템을 고르세요.

## 일반

- **추적 분석 없음**: OfficeVega에는 Google Analytics나 제3자 추적 도구가 없습니다. 문서 내용, 파일 이름, 사용 이벤트는 수집되거나 어디로도 전송되지 않습니다.
- **AI 사이드바 위치**(왼쪽 또는 오른쪽), **AI 패널 글자 크기**, **AI 채팅 맞춤법 검사**.
- **새 문서에서 AI 패널 열기** — 꺼져 있으면 새 문서는 패널이 접힌 상태로 시작하며, 한 번 클릭하면 열립니다.
- **모든 문서 자동 저장**은 모든 편집기에서 자동 저장을 기본으로 켭니다. 특정 창에서는 여전히 끌 수 있습니다.
- **저장 위치**와 **변경** 버튼, 그리고 **Office 문서 기본 앱**으로 .docx / .xlsx / .pptx를 OfficeVega가 열도록 지정할 수 있습니다.

## AI 미디어 및 검색

스위치가 아닙니다. 기능마다 그 기능을 제공할 업체를 고르고, 업체의 키와 기본 URL은 한 번만 입력하면 공유됩니다:

- **웹 검색**, **이미지 생성**, **이미지 분석**, **동영상 분석**은 각각 제공자, 모델, 키, 기본 URL을 가집니다. 업체로 **VEGA**를 고르면 로그인 키를 사용해 `api.vega.chat`을 통해 처리합니다.
- **로컬 파일 검색**은 이 컴퓨터에서 실행됩니다. 그 아래의 **Jev 검색 재순위화**는 **기본적으로 꺼져 있습니다**. 켜면 로컬 검색 상위 20개 결과의 발췌문(문서마다 최대 1,200자, 그리고 파일 및 폴더 이름)이 TypeSafe의 Jev 모델로 전송되어 관련도 순으로 다시 정렬됩니다. 꺼져 있으면 기기 밖으로 아무것도 나가지 않습니다.

## 정보

- **버전**, 프로젝트 사이트 [officevega.com](https://officevega.com), 릴리스 페이지 [officevega.com/releases](https://officevega.com/releases).
- **업데이트 채널**: 안정 버전 또는 베타 버전. 바꾸면 즉시 적용되고 업데이트를 확인합니다. 베타 버전으로 설치된 앱을 안정 버전으로 되돌리지는 않습니다.

## 기본 앱 연결

설정에서 OfficeVega를 .docx / .xlsx / .pptx / .pdf 등의 기본 열기 프로그램으로 등록할 수 있습니다(운영체제 수준의 기본 앱 등록이며, 묻는 창이 나오면 확인하세요).

## 제3자 고지와 업데이트

- 도움말 ▸ 제3자 고지: 앱에 포함된 전체 오픈소스 라이선스 목록입니다.
- 도움말 ▸ 업데이트 확인: 수동으로 확인합니다. 더 새로운 버전이 있으면 설치를 제안합니다.

## VEGA 로그인

- 로그인 항목(설정 또는 클라우드 프로젝트 목록)은 **기기 코드** 방식을 씁니다. OfficeVega가 코드를 보여 주고 브라우저 로그인 창을 엽니다. 로그인이 끝나면 자동으로 이어집니다.
- 로그인은 다음에만 사용됩니다: 클라우드 프로젝트 목록과 `api.vega.chat`의 VEGA 호스팅 모델. 로그인하지 않아도 모든 로컬 기능과 사용자 지정 모델은 계속 동작합니다.
- 로그아웃은 설정에서 한 번 클릭하면 됩니다.

## MCP 연동(고급 사용자 / AI 클라이언트용)

**연동**은 OfficeVega를 코딩 에이전트에 연결하는 패널이며, 이 주제만 다루는 별도 문서 「코딩 에이전트 연결」이 있습니다. 요약하면: 연결 방식(명령줄 또는 MCP)을 고르고, 그 절을 따라간 뒤, 새 대화를 시작해서 요청하면 됩니다.

![설정 ▸ 연동: 세 단계, 그다음 스킬 행과 MCP 옵션](img/settings-integrations.png)

**로컬 HTTP 서버** 아래에서 앱이 서버를 직접 실행할 수 있습니다(켜기 스위치, 포트). **고급**에서는 상태 확인 URL과 로그 파일을 추가로 설정합니다. localhost에서만 연결을 받습니다.

## 명령줄 요약

| 명령               | 하는 일                |
| ------------------ | ---------------------- |
| `officevega <file>` | 파일 열기              |
| `officevega mcp`    | 로컬 MCP 서버 시작     |
| `officevega --help` | 모든 명령과 옵션       |
