# การตั้งค่า ภาษา ธีม และการเชื่อมต่อ MCP

## การเปิดการตั้งค่า

แถวบัญชีที่มุมล่างซ้ายของหน้าแรกจะเปิดแผงการตั้งค่า (เมื่อยังไม่ได้ลงชื่อเข้าใช้ แถวนี้จะแสดงว่า "ลงชื่อเข้าใช้") แผงนี้มีหกส่วน ได้แก่ บัญชี, โมเดล AI, สื่อและการค้นหา AI, ทั่วไป, การเชื่อมต่อ และเกี่ยวกับ

![การตั้งค่า ▸ ทั่วไป ซึ่งเป็นที่ตั้งของภาษา ธีม การบันทึกอัตโนมัติ และสวิตช์สถิติการใช้งาน](img/settings-general.png)

การตั้งค่าโมเดลมีบทของตัวเอง ส่วน **สื่อและการค้นหา AI** คือที่ที่คุณเปิดการสร้างภาพ การวิเคราะห์ภาพ การวิเคราะห์วิดีโอ การค้นหาเว็บ และการค้นหาไฟล์ในเครื่อง แยกตามผู้ให้บริการแต่ละราย

## ภาษา

- การตั้งค่ามี **21 ภาษาสำหรับส่วนติดต่อผู้ใช้** ได้แก่ อังกฤษ, จีนตัวย่อ, ญี่ปุ่น, เกาหลี, ฝรั่งเศส, เยอรมัน, สเปน, ไทย, อินโดนีเซีย, รัสเซีย, อาหรับ, โปรตุเกส, อิตาลี, โปแลนด์, เช็ก, ดัตช์, มาเลย์, ฮีบรู, ฮินดี, จีนตัวเต็ม และเวียดนาม
- การเปลี่ยนภาษามีผลทันทีและถูกบันทึกไว้ แถบเมนูของระบบจะถูกสร้างใหม่ตามภาษานั้น

## ธีม

สว่าง / มืด / ตามระบบ โหมดตามระบบจะเปลี่ยนตามรูปลักษณ์ของระบบปฏิบัติการ และพื้นที่แก้ไขจะเปลี่ยนสีตามโดยไม่กะพริบ การสลับนี้ยังเปลี่ยนสีของแผง AI และหน้าแรกด้วย เพื่อให้ทั้งแอปใช้ดีไซน์เดียวกัน: เลือกสว่างสำหรับห้องที่สว่าง มืดสำหรับการทำงานตอนกลางคืน หรือตามระบบเพื่อให้เป็นไปตาม Windows

## ทั่วไป

- **ส่งสถิติการใช้งานแบบไม่ระบุตัวตน**: เปิดใช้งานเป็นค่าเริ่มต้น ใช้ Google Analytics 4 และส่ง IP สาธารณะกับข้อมูลเมตาของการรับส่งข้อมูล ไม่มีการเก็บเนื้อหาเอกสาร ชื่อไฟล์ หรือเหตุการณ์การใช้งานใด ๆ ไปที่อื่น
- **ตำแหน่งแถบด้านข้าง AI** (ซ้ายหรือขวา), **ขนาดตัวอักษรของแผง AI** และ **ตรวจการสะกดในแชต AI**
- **เปิดแผง AI ในเอกสารใหม่**: เมื่อปิดไว้ เอกสารใหม่จะเริ่มด้วยแผง AI ที่ยุบอยู่ และคลิกเพียงครั้งเดียวก็เปิดได้
- **บันทึกอัตโนมัติทุกเอกสาร**: เปิดการบันทึกอัตโนมัติเป็นค่าเริ่มต้นในทุกตัวแก้ไข แต่ยังปิดเฉพาะหน้าต่างใดหน้าต่างหนึ่งได้
- **ตำแหน่งที่บันทึก** พร้อมปุ่ม **เปลี่ยน** และ **แอปเริ่มต้นสำหรับเอกสาร Office** เพื่อให้ไฟล์ .docx / .xlsx / .pptx เปิดด้วย OfficeVega

## สื่อและการค้นหา AI

ไม่ใช่สวิตช์ แต่ละความสามารถจะเลือกผู้ให้บริการที่ให้บริการความสามารถนั้น และคีย์กับ URL ฐานของผู้ให้บริการจะกรอกเพียงครั้งเดียวแล้วใช้ร่วมกัน:

- **ค้นหาเว็บ**, **สร้างภาพ**, **วิเคราะห์ภาพ** และ **วิเคราะห์วิดีโอ** แต่ละรายการมีผู้ให้บริการ โมเดล คีย์ และ URL ฐาน เลือก **VEGA** เป็นผู้ให้บริการเพื่อส่งคำขอผ่าน `api.vega.chat` ด้วยคีย์การลงชื่อเข้าใช้ของคุณ
- **การค้นหาไฟล์ในเครื่อง** ทำงานบนเครื่องนี้ ภายใต้หัวข้อนี้มี **การจัดอันดับใหม่ด้วย Jev** ซึ่ง **ปิดเป็นค่าเริ่มต้น** เมื่อเปิด ข้อความตัดตอนของผลการค้นหาในเครื่อง 20 อันดับแรก (สูงสุด 1,200 อักขระต่อเอกสาร พร้อมชื่อไฟล์และชื่อโฟลเดอร์) จะถูกส่งไปยังโมเดล Jev ของ TypeSafe เพื่อจัดอันดับใหม่ตามความเกี่ยวข้อง เมื่อปิดอยู่ จะไม่มีข้อมูลใดออกจากอุปกรณ์

## เกี่ยวกับ

- **เวอร์ชัน**, เว็บไซต์โปรเจกต์ [officevega.com](https://officevega.com) และหน้าเผยแพร่ [officevega.com/releases](https://officevega.com/releases)
- **ช่องทางอัปเดต**: เสถียร หรือ เบต้า การเปลี่ยนแปลงมีผลทันทีและจะตรวจหาอัปเดต แต่จะไม่ย้อนการติดตั้งเบต้ากลับไปเป็นเสถียร

## การผูกแอปเริ่มต้น

การตั้งค่าสามารถลงทะเบียน OfficeVega เป็นโปรแกรมที่เปิดไฟล์ .docx / .xlsx / .pptx / .pdf และไฟล์อื่น ๆ ได้ (เป็นการลงทะเบียนแอปเริ่มต้นระดับระบบปฏิบัติการ ให้ยืนยันเมื่อระบบถาม)

## ประกาศซอฟต์แวร์ของบุคคลที่สามและการอัปเดต

- วิธีใช้ ▸ ประกาศซอฟต์แวร์ของบุคคลที่สาม: รายการใบอนุญาตโอเพนซอร์สทั้งหมดที่มากับแอป
- วิธีใช้ ▸ ตรวจสอบการอัปเดต: เริ่มการตรวจสอบด้วยตนเอง หากมีเวอร์ชันใหม่กว่า จะแจ้งให้ติดตั้ง

## การลงชื่อเข้าใช้ VEGA

- จุดเข้าใช้งานการลงชื่อเข้าใช้ (ในการตั้งค่าหรือในรายการโปรเจกต์บนคลาวด์) ใช้ขั้นตอน **รหัสอุปกรณ์**: OfficeVega จะแสดงรหัสและเปิดหน้าเข้าสู่ระบบในเบราว์เซอร์ แล้วดำเนินการต่อโดยอัตโนมัติเมื่อเสร็จ
- การลงชื่อเข้าใช้ใช้เพื่อ: รายการโปรเจกต์บนคลาวด์และโมเดลที่ VEGA โฮสต์ไว้ที่ `api.vega.chat` เท่านั้น หากไม่ได้ลงชื่อเข้าใช้ ฟีเจอร์ในเครื่องทั้งหมดและโมเดลที่กำหนดเองยังทำงานได้ตามปกติ
- การออกจากระบบทำได้ด้วยคลิกเดียวในการตั้งค่า

## การเชื่อมต่อ MCP (สำหรับผู้ใช้ขั้นสูง / ไคลเอนต์ AI)

**การเชื่อมต่อ** คือแผงที่เชื่อม OfficeVega กับเอเจนต์เขียนโค้ด และมีบทของตัวเอง ได้แก่ การเชื่อมต่อเอเจนต์เขียนโค้ด สรุปสั้น ๆ คือ เลือกเส้นทาง (บรรทัดคำสั่งหรือ MCP) แล้วทำตามส่วนนั้น จากนั้นเริ่มแชตใหม่และถามได้เลย

![การตั้งค่า ▸ การเชื่อมต่อ: สามขั้นตอน ตามด้วยแถวสกิลและตัวเลือก MCP](img/settings-integrations.png)

ภายใต้ **เซิร์ฟเวอร์ HTTP ในเครื่อง** แอปสามารถรันเซิร์ฟเวอร์นี้ได้เอง มีสวิตช์เปิดใช้งานและพอร์ต ส่วน **ขั้นสูง** จะเพิ่ม URL สำหรับตรวจสุขภาพของเซิร์ฟเวอร์และไฟล์ล็อก โดยเซิร์ฟเวอร์จะรับการเชื่อมต่อเฉพาะบน localhost เท่านั้น

## ตารางคำสั่งบรรทัดคำสั่งแบบย่อ

| คำสั่ง              | ทำอะไร                         |
| ------------------- | ------------------------------ |
| `officevega <file>` | เปิดไฟล์                       |
| `officevega mcp`    | เริ่มเซิร์ฟเวอร์ MCP ในเครื่อง |
| `officevega --help` | คำสั่งและตัวเลือกทั้งหมด       |
