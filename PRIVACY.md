# GetOffice Privacy

Last updated: September 18, 2026

GetOffice opens, edits, and saves documents locally. Document editing does not
upload files to GetOffice. AI features require a network connection and send
requests only when you use them.

## Usage analytics

GetOffice does not collect or send any usage analytics or telemetry.

## Data not collected

GetOffice never sends:

- document content
- file names
- file paths
- account identity
- email addresses
