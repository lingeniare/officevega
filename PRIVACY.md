# OfficeVega Privacy

Last updated: September 18, 2026

OfficeVega opens, edits, and saves documents locally. Document editing does not
upload files to OfficeVega. AI features require a network connection and send
requests only when you use them.

## Usage analytics

OfficeVega does not collect or send any usage analytics or telemetry.

## Data not collected

OfficeVega never sends:

- document content
- file names
- file paths
- account identity
- email addresses
