# OfficeVega 0.5.0

**Дата релиза:** 2026-11-17

Фича-релиз: версии документа в ИИ-панели всех редакторов, новый фирменный стиль и более живучее автообновление.

## ИИ

- Версии документа: каждый запрос к ИИ сохраняет восстанавливаемый снимок — исходное состояние, ручные правки между запросами и результат каждого промта (включая прерванные)
- Меню истории в ИИ-панели: поиск по промтам и откат к любой версии одним кликом; текущее состояние сохраняется перед откатом, старые версии не удаляются
- История привязана к файлу и переживает перезапуск приложения; «Сохранить как» переносит её в новый файл
- Время в истории показывается на языке интерфейса («вчера», «yesterday» и т.д.)

## Документы

- Снимок версии захватывает документ целиком: секции, колонтитулы, водяной знак, сноски, комментарии и список источников — откат возвращает и их

## Таблицы

- Версия книги снимается полным снимком файла — без лишнего сохранения на диск и без потери журнала правок

## PDF

- Версия хранит байты файла вместе с незавершёнными правками: скрытия текста, вложения, шифрование; «Сохранить копию» передаёт историю копии

## Приложение

- Новый фирменный стиль: иконка «раскрытая книга со звездой» в приложении, установщике и редакторах; логотип в боковой панели — четырёхлучевая звезда
- Автообновление: при сбое сети проверка повторяется через 5 минут, прерванное скачивание продолжается с места обрыва
- Автообновление: фоновая загрузка показывает живой прогресс в Настройки → О приложении, а по завершении сама открывает карточку «Обновить»
- Автообновление: при неустранимой ошибке скачивания карточка предлагает ссылку на ручную загрузку вместо молчаливого ожидания
