## Что вошло

### PDF

- Открытие **зашифрованных паролем PDF** (дешифровка потоков до парсера).
- **Сравнение документов**: текстовый diff с выбранным файлом,
  постранично; идентичные страницы за лимитом считаются равными.
- **Панель вложений** — список/добавление/экспорт/удаление встроенных
  файлов.
- **Измерительная линейка** с калибровкой — реальная длина по линии.
- **Сжатие файла** — перепаковка потоков и даунсэмпл картинок в копию.
- **Редактируемые закладки** — добавить/переименовать/удалить в outline.
- **Bates-нумерация** страниц.
- **Гиперссылки**: добавление и правка (Edit → Link).
- **Панель комментариев** со всеми заметками документа.
- Аннотации: волнистое подчёркивание, каретка, полигон.
- **Baked OCR** — распознанный текст пишется в файл при сохранении,
  страницы становятся доступны поиску.
- Поиск: **учёт регистра** и «слово целиком».
- Экспорт страниц в **JPG**.
- Фикс: стем имён с двоеточием на Windows.

### Sheets

- **Зашифрованные книги** и смена пароля.
- **x14-валидация** данных — чтение и запись.
- **Пароли на разрешённые диапазоны** редактирования.
- **Проверка орфографии** в книге.
- **What-If таблицы данных** (одна/две переменные).
- **PivotCharts** при сохранении; stdDev/stdDevp/var/varp в «Суммировать
  по»; остальные 8 режимов Show Values As; Select Data и смена типа для
  комбо-диаграмм.
- Фильтры Excel-таблиц сохраняются.
- Из legacy **.xls** переносятся картинки, объединения, ширины колонок и
  высоты строк (escher/xls_biff; calamine 0.37).
- Картинка в примечании.
- Именование книги по просьбе.
- Фиксы: книги с абсолютными OPC-таргетами (openpyxl); правка формул при
  cellXfs без xfId; `add_chart` с формульным диапазоном; сообщение при
  отказе тумблера фильтра; хэши паролей диапазонов при повторном
  применении; над-/подстрочный текст; сон outline-gutter; рамка
  скопированного диапазона; headless-экспорт всех листов в PDF.

### Markdown

- **Сноски** `[^метка]` + `[^метка]:` определения.
- **`==highlight==`** инлайн-разметка.
- **Block ids** — ссылка на любой блок, как в Obsidian.
- **Сайдбар тегов**: все `#теги` хранилища с файлами.
- Wiki-ссылки: `[[`-подсказка показывает заголовки и block-id после `#`;
  алиас показывается вместо ссылки; несуществующая ссылка создаёт
  заметку; вставленная ссылка/`![[embed]]` работает сразу.
- Слова и символы в статус-баре.
- Именование файла по просьбе.
- Фиксы: широкие таблицы умещаются, Escape закрывает граф, cross-folder
  embed-картинки.

### Slides

- **Лента мастера слайдов** — текстбоксы, фигуры, линии.
- Размеры слайдов: **A4/A3, портрет, произвольный**.
- Экспорт в **JPG**.
- Именование колоды по просьбе.
- Фиксы: оборванное сохранение не портит прошлый файл; меньше трафика
  после правок слайдов.

### Docs

- **Поворот плавающих фигур** и толщина обводки; выделение поворачивается
  с фигурой; header/footer хранят transform и stroke.
- Маркеры/нумерация/отступы в текстбоксах и фигурах.
- Именование файла (в т.ч. из File-меню macOS).
- Фиксы: разрыв страницы не уезжает при правке текста; картинки
  двигаются/ресайзятся как в Word; позиция вставленной картинки после
  сохранения; объединённые ячейки через разрыв страницы; ширина таблицы
  при удалении столбца; заголовок без стилей; compare целых абзацев;
  fold-ручки в структуре; SEQ-поля с экранированием.

### HTML

- Выравнивание «по ширине».
- ИИ ищет и генерирует картинки для страницы.
- Именование файла по просьбе.

### Shell / общее

- **Restore session**: опция открытия документов прошлой сессии.
- Ресайз домашнего сайдбара за край.
- Выключатель авто-проверки обновлений.
- Тумблеры спячки вкладок и аналитики в настройках.
- ИИ-именование файлов с домашнего экрана.
- **Скиллы в `~/.agents`** с чисткой унаследованных per-tool копий.
- Спеллчек следует за языком UI (не только за ОС).
- MCP `insert_picture` для видимого документа.
- Иконка AI-меню PDF при 100% DPI.

  MiMo, Hunyuan, Ling, Spark, LongCat — и их тесты/логотипы.
- Маршрут **OpenAI Decisions** (GA API) — вычищен из decider/rerank.
- Локали за пределами наших 9 (tr/zh/vi/… файлы удалены при мерже).
- `genoffice`-брендинг в новых диалогах/путях — переведён на officevega
  (CLI `officevega.cjs`, skills/officevega, temp-пути).
