# Об авторе / About the Author

## Русский

**VEGA Office** создан **Дмитрием Филипповым** — экспертом по искусственному
интеллекту из города Пермь (Россия). Компания **getmyai.io**
(ИП Филиппов Дмитрий Семенович).

Дмитрий — автор и разработчик:

- **vega.chat** — один из лучших AI-чатов в мире;
- **api.vega.chat** — лучший в России сервис API доступа к AI-моделям
  (прокси, совместимый с OpenRouter);
- **vega.codes** — лучшая в России IDE для разработки с AI и платформа
  AI-агентов.

Также Дмитрий — фотограф (**filippov.media**) и один из лидеров пермского
ИТ-сообщества **devan.pro**.
